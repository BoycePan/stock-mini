# 前端图标素材清单（QUOTE_ICONS + 金店 / 个股公司 Logo）

> 整理对象：`front/` 业务代码里需要替换成图片的图标素材，共三类：
> ① 行情卡片图标 `QUOTE_ICONS`（板块 / 类型 / 指数 / 汇率 / 金属等，`front/utils/quote-pages.ts`）
> ② 金店金价品牌的 **公司 Logo**（`front/config/gold-shop.ts` 的 `GOLD_SHOP_BRANDS`，15 家）
> ③ QUOTE_ICONS 中的 **日韩个股公司 Logo**（三星电子、SK海力士、丰田等 16 家）
>
> 说明：自定义 iconfont（`styles/font.wxss`）与 TDesign 组件内置图标**不在本次替换范围**。
> 抓取脚本：`front/scripts/fetch-icons.py`（Python 3，依赖 `requests` + `Pillow`，
> SVG 转 PNG 另需 `resvg-py`：`pip install resvg-py`）。

## 一、QUOTE_ICONS（行情卡片图标）

- 定义：`front/utils/quote-pages.ts` 的 `QUOTE_ICONS: Record<string, string>`
- 渲染：`front/components/section-card/index.wxml:39`（`metric-icon-chip`）
- 下游复用：`front/utils/share-poster.ts`（分享海报绘制）
- 抓取：按 Twemoji 15.1 文件名规则（去 `FE0F` 变化选择符，码点小写 hex 用 `-` 连接）

  仅保留 **72px 正方形原图**（体积小，不再输出放大版）。

## 四、抓取脚本与代码接入

`front/scripts/fetch-icons.py`：

```bash
pip install requests pillow resvg-py   # resvg-py 仅 SVG 转 PNG 需要
python front/scripts/fetch-icons.py [--out front/static/icons] [--size 256]
```

输出结构（**全部为正方形 PNG**，长宽不足自动透明补边，体积已压缩）：

```
front/static/icons/
├── emoji/            # QUOTE_ICONS：<twemoji名>.png（72px 正方形原图，无放大版）
├── metal/            # gold-bar.png / silver-bar.png（256×256，脚本生成金条/银条）
├── brand/            # 15 家金店：<品牌名>.png（256×256，官网 logo 或占位图）
├── company/          # 16 家日韩个股公司：<公司名>.png（256×256，公司 logo）
├── manifest.json     # 全量清单 + code_map（每个行情 code → 最终图片路径）
└── (由脚本同时生成) front/config/icon-assets.ts   # 供业务代码引用的路径映射
```

- manifest 每条记录 `status`：`ok`（真实图片）/ `generated`（脚本生成）/ `placeholder`
  （占位图，需人工替换）/ `failed`（抓取失败）；
- **`code_map`**：如 `"005930": "company/三星电子.png"`、`"GOLD": "metal/gold-bar.png"`、
  `"sh000001": "emoji/1f1e8-1f1f3.png"`，替换页面时按行情 code 直接取图。

### 已接入的业务代码（2026-02 完成）

| 文件 | 接入内容 |
| --- | --- |
| `front/config/icon-assets.ts` | 脚本生成：`QUOTE_ICON_ASSETS`（行情 code → 图片路径）、`GOLD_SHOP_ICON_ASSETS`（金店品牌 → logo 路径） |
| `front/utils/quote-pages.ts` | `metricOf` 填充 `iconImage: item.iconImage ?? QUOTE_ICON_ASSETS[item.code]` |
| `front/api/market.ts` | 金店金价条目 `iconImage: GOLD_SHOP_ICON_ASSETS[shop]`（按品牌取 logo） |
| `front/types/market.ts` | `MarketMetric` / `QuoteItem` 增加 `iconImage?: string` |
| `front/components/section-card/index.wxml` | `metric-icon-chip` 有 `iconImage` 时渲染 `<image>`，否则回退 Emoji `<text>` |
| `front/utils/share-poster.ts` | 海报行图标改为 `drawImage`（预加载全部本地图标），无图回退 Emoji / 国旗文字徽标 |
| `front/project.config.json` | `ignoreUploadUnusedFiles: false`（图标路径为数据绑定动态引用，需随包上传，避免生产包缺图） |

> 说明：自定义 iconfont（TabBar）与 TDesign 组件图标不在本次替换范围；
> 财经页新闻（📰）、上金所实物金（🏛️）等未生成图片的条目仍回退 Emoji。

## 五、替换为 PNG 时的注意事项

1. **QUOTE_ICONS / section-card**：`metric-icon-chip` 已支持 `<image>`（32rpx，透明补边图
   aspectFit），深浅主题下底色为淡蓝 chip，品牌 logo 建议保留底色容器保证可读；
2. **share-poster.ts**：海报行图标已改为 `drawImage`（本地图预加载，失败回退 Emoji）；
3. **金店 logo**：按品牌名（`GS-${shop}`）取 `brand/<品牌名>.png`，不再是单一 🏬；
4. **个股公司 logo**：日韩个股按 code 取 `company/<公司名>.png`（`QUOTE_ICON_ASSETS`）；
5. **主题兼容（强制，见 AGENTS.md）**：图片为透明底 PNG，浅色/深色主题均需可读；
6. **本地化**：图标已全部落在 `front/static/` 随包发布，无外网请求；
7. **占位图**：6 家金店（菜百/潮宏基/金至尊/梦金园/亚一金店/水贝黄金）为脚本生成的
   金色文字占位图，如需正式 logo 可人工替换同名文件后重跑脚本。
