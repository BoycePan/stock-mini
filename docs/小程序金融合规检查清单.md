# 小程序金融功能合规检查清单

> 对象：`front/` 小程序（市场追踪助手 / 行情追踪助手）拟新增/优化的功能。
> 目的：判断把推荐的功能放进小程序，**是否踩合规红线**，以及需要什么资质/调整。
> 生成日期：2026-08-27

## 1. 三条贯穿全局的红线（先确定边界）

### 1.1 「行情信息」≠「投资咨询」

《证券法》第160条：**从事证券投资咨询业务需取得证监会许可（牌照）**。无牌照不得：
- 对具体证券**作出买卖建议**；
- **推荐**个股/板块、**预测**涨跌走向、给出目标价；
- 以「荐股、带你炒股、稳赚/必涨」等话术诱导。

> **判定标准**：只要是**客观、事实性、不给出判断与倾向**的展示（价格、涨跌幅、涨跌停家数、
> 成交额、K线、分时），风险低；一旦输出**「看好/建议买入/看多/可能反弹/重点关注」**这类
> 主观判断或推荐，就踩线。

### 1.2 虚拟货币是「类目敏感 + 原则性禁止炒作」

中国对虚拟货币的定调：**不具有与法定货币等同的法律地位，禁止交易、炒作、代币融资**，
并禁止为虚拟货币交易提供 **营销宣传** 等服务。微信平台对**虚拟货币交易/炒作**类小程序
管控严格，违规会被拒审或下架。

> **判定标准**：纯客观展示 BTC/ETH 公开市场**价格**（不涉交易、不宣传、不引导），风险相对
> 可控，但**极易被审核判为「引导炒作」**，是本次建议里**风险最高**的一项。

### 1.3 个人信息（PIPL）最小化 + 告知同意

自选、持仓、记账等属**个人信息**。收集、上传服务器都需要：明示用途、取得同意、最小化收集、
**隐私协议与实际情况一致**。

> **判定标准**：纯本地存储风险最低；凡「云端同步/上传」，必须在隐私协议明示并取得同意。

## 2. 逐项合规判定

| # | 功能 | 合规等级 | 关键风险点 | 建议 |
| --- | --- | --- | --- | --- |
| 1 | **自选股 + 分组（本地版）** | 🟢 低风险，可直接做 | 仅本地存储，属个人信息但不上传 | 直接做；隐私协议若已写「仅存本地」则一致 |
| 2 | **自选（云端同步）** | 🟠 中，需配套 | 自选数据上传服务器 | 隐私协议必须写明「会同步到服务器」，取得同意，说明用途与保存策略 |
| 3 | **价格/异动提醒（客观触发）** | 🟠 中，需谨慎**文案** | 触发逻辑本身客观（达到某价/涨跌幅）；但若通知配「可关注/机会」类话术即变荐股 | 通知**只报客观事实**（如「已回落至 200 元」），绝不加主观评价；提醒是用户自设，不主动推荐 |
| 4 | **微信订阅消息** | 🟠 中 | 订阅模板需审核；金融/市场类模板审核较严；不能高频打扰 | 走规范订阅（一次性/长期按平台规则），内容合规、频率克制 |
| 5 | **大盘情绪/涨跌停/连板/涨跌比** | 🟡 中低 | 客观统计，风险低；但要如实标注数据口径与时点 | 可做；展示处配免责声明（数据为公开口径、可能延迟、仅供参考） |
| 6 | **板块成分股联动 / 人气板块** | 🟢 低 | 客观数据 | 可做 |
| 7 | **持仓/记账/模拟组合** | 🟢 低（本地）/ 🟠 中（上云） | 强个人信息 | 推荐**纯本地**；若做云端同步，同第2项需隐私告知同意 |
| 8 | **财经日历（宏观数据/财报/打新/分红）** | 🟢 低 | 客观、提前知道事件 | 可做；不要把「利好/利空」预判写成建议；打新/分红属客观公告 |
| 9 | **加密数字货币行情** | 🔴 **高风险** | 类目敏感、被解读为「引导炒作」、易被拒审/下架 | **调整口径很关键**：只做「公开市场价格/指数」资讯、明确「不构成投资建议、不提供任何交易服务、不代表认可虚拟货币」；**最好先与平台确认类目**，难以把握时**建议暂缓或谨慎上架** |
| 10 | **AI 智能解读** | 🔴 **高风险** | AI 生成「简评/看多/建议」极易构成**无牌证券投资咨询**；输出不可控 | 只有两种稳妥做法：①**严格限定为「信息整理/摘要/翻译」**（事实性、无判断、无推荐），且加免责；②**人工复核后再发布**。绝不能直接放 AI 观点性/建议性内容。难以保证时**不建议** |
| 11 | **补齐全球指数/全球ETF板块** | 🟢 低 | 客观行情 | 可做（注意数据源真实的时效标注） |
| 12 | **广告位扩充 / 激励视频** | 🟠 中 | 金融类目的广告限制；禁「荐股/高收益/某股必涨」类**诱导性金融广告**；激励视频需合规 | 只能放合规广告位，内容不得诱导投资；避开「机会/稳赚」话术 |
| 13 | **订阅消息召回/回访** | 🟠 中 | 配合提醒；模板与频率合规 | 按「订阅消息」规范使用，用户订阅前提，不强制 |

## 3. 按「是否触碰红线」的三档结论

**🟢 可以直接做（低风险，客观数据为主）**
- 自选 + 分组（本地版）
- 补齐指数 / 全球 ETF 板块
- 板块成分股联动 / 人气板块
- 持仓 / 记账 / 模拟组合（**纯本地**）
- 财经日历

**🟠 可以做，但必须「带条条框框」**
- 价格 / 异动提醒 + 订阅消息：**通知只报事实、不报判断**；走合规模板；频率克制。
- 自选/持仓**云端同步**：隐私协议如实写明 + 同意。
- 广告位扩张：**非诱导性**金融广告 + 合规内容。

**🔴 风险最高，建议谨慎 / 调整口径 / 暂缓**
- **加密数字货币行情**：最容易踩「虚拟货币炒作」红线；需改口径（纯资讯、明确不构成建议、
  不涉交易宣传），并**先确认平台类目**；难以把握就暂缓。
- **AI 智能解读**：最可能构成**无牌证券投资咨询**；只做「事实整理/摘要」+免责+人工复核，
  否则不建议。

## 4. 类目 / 资质层面（微信公众平台）

1. 现状是小程序以「行情资讯 / 工具」形态存在，**纯客观行情 + 资讯**通常归入
   **金融-金融资讯** 或 **工具-信息查询** 类，属相对低门槛。
2. **一旦涉及「投资建议/荐股/预测」**，就需要**证券投资咨询资格**（或接入持牌机构/持牌
   内容），否则违规。这是本项目最大的合规软肋——**必须在产品层面主动控制，不输出建议**。
3. **加密货币**：微信对虚拟货币业务限制严格，展示类小程序审核时经常被拒；**新增此类功能
   前务必先查平台当前是否允许该业务形态**。
4. 任何**新增外部直连数据源**还要在公众平台配置 **request 合法域名**（技术前置，非合规线，
   但不配真机会挂）。

## 5. 上线前的合规自查清单（Checklist）

- [ ] 所有行情/统计均**客观展示 + 免责声明**（公开接口数据、可能延迟、仅供参考、不构成投资建议）。
- [ ] 全站**无**「荐股 / 推荐买入 / 稳赚 / 必涨 / 带你炒股 / 关注某股」等诱导或建议性话术。
      （可对照 `docs/小红书文案规范.md` 的禁用词。）
- [ ] 隐私协议**与实际功能一致**（之前发现「提到自选仅存本地、实际却无此功能」的错位，务必修）。
- [ ] 任何**云端同步**的个人信息（自选/持仓/收藏）在隐私协议中**如实写明并取得同意**。
- [ ] 加密功能**要么不做，要么改口径**（纯资讯 + 明确不构成建议 + 不涉交易宣传），并已与平台确认。
- [ ] AI 功能**只做事实整理/摘要**，无观点无推荐，加免责，必要时人工复核。
- [ ] 提醒/订阅消息**只报客观触发**，不报判断；模板合规、频率克制。
- [ ] 新增外部数据源的 **request 合法域名**已配置，且口径以真实来源为准。
- [ ] 新闻/快讯**来源与时效**如实标注；无标题党/夸大。
- [ ] 广告位**无诱导性**金融内容。
- [ ] 已核对**最新**《微信小程序平台运营规范》与当前「金融」类目要求。

## 6. 一句话结论

把「客观行情 + 自选/提醒（只看事实）+ 资讯 + 记账」做进小程序是**低到中风险、总体可控**的；
但**「加密行情」和「AI 给出看法的解读」两条是真正的红线**——前者涉嫌「虚拟货币炒作」、
后者涉嫌「无牌证券投资咨询」。**本小程序最大的合规底线是：永远只展示客观事实、绝不输出
「建议/推荐/预测」，并配套免责声明与真实一致的隐私协议。**
