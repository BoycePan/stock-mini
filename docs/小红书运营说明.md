## 一、流量机制速览

小红书的推荐不是「一次定生死」，而是**阶梯式流量池 + 数据赛马**：

| 阶段 | 曝光量级（约） | 决定晋级的核心数据 |
| --- | --- | --- |
| 初始流量池 | 100–500 次曝光 | 点击率（封面 / 标题）、完读率、互动率 |
| 次级流量池 | 1000–5000 | 互动率持续、收藏率（干货价值）、评论率 |
| 大流量池 | 1 万–10 万+ | 互动总量、搜索命中、账号权重 |

**关键结论（业界共识的「CES 评分」权重，仅供参考的量级排序）**：

> 关注 ＞ 转发/评论 ＞ 收藏 ＞ 点赞 ＞ 完读/完播

也就是说：**让用户「收藏」和「评论」比单纯点赞更值钱**。小红书笔记的收藏率是硬通货，
因为「收藏 = 对我有用 = 干货」。这决定了我们写文案的策略——**做成「有用的工具清单 + 比价攻略」，
而不是「广告」**。

三个决定生死的前置指标：

1. **点击率（封面 + 标题）**：决定用户是否点进来。首图 0.5 秒法则——用户滑到时只有半秒决定。
2. **完读率（正文）**：决定用户是否看到最后（看到最后才有收藏 / 关注动机）。正文要短、可扫读。
3. **互动率（收藏 / 评论 / 转发）**：决定能否滚进下一级流量池。要埋「互动钩子」。

> 参考来源：小红书算法机制与 CES 评分，见文末 [参考来源](#八参考来源) ①②③。

## 二、提升访问量的实操规律

### 2.1 账号定位（先于内容）

- **垂直**：一个号只做一类（黄金比价 / 全球行情 / 实用工具），不要今天美食明天股票。垂直号更容易被算法打标、推给精准人群。
- **人设真实**：素人号比硬广号跑量好。用「我最近在挑金饰」「我平时看行情」这类第一人称真实场景，别用品牌官方口吻。
- **新号养号**：前 5–10 篇先发「纯干货 / 经验」内容（不推产品），等账号有了基础权重和标签再逐步带产品，降低被判定「营销号」的概率。

### 2.2 封面（点击率的第一战场）

- **尺寸**：竖版 **3:4**（1242×1656 px）是最稳的爆款比例，信息展示面积大；1:1 次之。别用横图。
- **0.5 秒法则**：封面必须一眼看懂「这条对我有什么用」。
  - 用**大字标题**压图（一句话讲清价值，如「42 家金店金价 一屏比完」「全球行情 不用下 APP」）。
  - **高对比 + 信息密度**：深色界面截图 + 醒目标题文字，比纯风景图点击率高。
  - 避免：文字太多、看不清、无重点、与标题重复。
- **真人 / 实物感**：黄金比价这类选题，真人拿手机 + 金饰柜台的实景图比纯 UI 截图更有代入感（见生图提示词「生活场景封面」）。

### 2.3 标题（决定点不点）

- **公式**：`数字 + 场景/痛点 + 结果钩子`，或 `反常识/悬念`。
  - 好例子：「买金前先比价！金店金价一个小程序看完」「金价一天一个价，出门前先打开它比一圈」
  - 坏例子：「最好的行情小程序」「不看后悔」（踩极限词 / 诱导词，直接限流）。
- 控制在 **18–20 字以内**，把最硬的卖点放最前面。
- 一个笔记准备 **3–4 个标题备选**，发布后数据差可换标题重发测试。

### 2.4 正文（完读率 + 收藏率）

- **前 3 行定生死**：开头一句真实场景钩子（「挑金饰，比价真麻烦」），别上来就罗列功能。
- **结构扫读化**：短段落 + emoji 分点 +「·」列表，一段不超过 2–3 行。
- **先种草后降温**：讲完亮点，主动写 1–2 条真实局限（「没有自选股分组、没有价格提醒」），
  这种「不吹」反而提高可信度和完读率，也躲开「硬广」判定。
- **埋互动钩子**：结尾问一句（「你们买金前会先比价吗？」「还有人不知道能一屏看全球指数吗？」），引导评论。
- **结尾必带免责声明**（见 3.3，金融类目必须）。

### 2.5 标签（话题 #）

- **8–12 个**，从大到小分层：大类词（#小程序 #黄金 #金价）→ 中类词（#财经资讯 #行情）→ 长尾词（#金店比价 #实用小程序 #日常分享）。
- 每条笔记**固定一个核心关键词**贯穿标题、正文、标签（如主打「金店比价」，三个位置都带「金价/比价」），利于搜索排名。
- 别堆 20 个无关标签，会稀释权重。

### 2.6 发布时间与频率

- **黄金时段**（多数经验共识）：**早 7–9 点、午 12–14 点、晚 20–22 点**。财经/行情类偏早高峰（开盘前）和晚高峰（下班刷）。
- **频率**：起步**一周 3–5 篇**稳定更新，别一天发 10 篇（易被判营销号限流），也别一周 1 篇。
- **稳定 > 爆发**：算法看重账号活跃度和稳定性，坚持比单篇爆款更重要。

### 2.7 冷启动与养数据

- 发布后 1 小时内，笔记处于初始流量池，**第一时间回复所有评论**（提高互动权重）。
- 真实朋友互赞互藏有效，但**不要**机械刷量 / 买量（平台能识别，直接限流）。
- 数据差就复盘封面 / 标题，换一个重发，而不是盲目堆量。

### 2.8 引流（合规地让用户找到产品）

- 小红书**禁止站外导流**（个人微信、二维码、电话、群号一律不写，正文连「微信」都不提更稳）。
- 合规引流路径：**正文不写任何联系方式**，引导用户在平台内「私信 / 评论问我」，或引导
  「搜小程序名『市场追踪助手』」——小程序是微信生态，但**先确认是否已上架、搜一搜能否搜到**再写这句。
- 产品内已有入口：设置页「问题反馈」（扫码联系开发者）。正文可写「有不懂的评论区问我」，把互动留在平台内。

> 参考来源：封面 / 标题 / 发布时间 / 频率 / 涨粉方法，见文末 [参考来源](#八参考来源) ④⑤⑥⑦⑧⑨。

## 三、违禁词与推广检测红线

> 本项目属**金融 / 财经 / 黄金**高敏类目，小红书 2026 年已专项治理「港美股开户诱导、荐股、倒卖研报」等，
> 一次性处置账号数万个。所以下面的红线**比普通种草更严**，宁可写得「素」一点，也不要碰线。

### 3.1 极限词 / 绝对化用语（通用红线，任何类目都查）

| 类别 | 举例（写文案时全部避开） |
| --- | --- |
| 「最」字头 | 最好、最佳、最高、最低、最便宜、最全、最新、最专业、最实用 |
| 「一」字头 | 第一、唯一、独一无二、全网第一、排名第一、NO.1、TOP.1 |
| 「级/顶/极」 | 国家级、世界级、顶级、极致、极品、绝对、终极、完美、无与伦比 |
| 「首/独」 | 首个、首选、独家、全网首发、首次、首款 |
| 夸张词 | 遥遥领先、天下第一、绝无仅有、无人能及、空前、史无前例 |

**替代写法**：把「最全的行情工具」改成「行情聚合得比较全的一个小程序」；「最好用」改成「用起来顺手」。

### 3.2 金融类目专项红线（本项目最危险的地带，逐条背诵）

| 禁止 | 正确写法 |
| --- | --- |
| ❌ 荐股 / 买卖点：「推荐买入」「建议持有」「目标价」「止损位」 | ✅ 只讲「能看行情」，绝不评价该不该买 |
| ❌ 收益承诺：「稳赚」「必涨」「保本」「高收益」「翻倍」「带你炒股」 | ✅ 「数据仅供参考，不构成投资建议」 |
| ❌ 收益相关词：「收益率」「投资回报」「无风险回报」「升值」「众筹」 | ✅ 用「看行情」「比价格」替代一切收益表述 |
| ❌ 开户/交易诱导：「开户」「入金」「交易」「跟单」「加仓」 | ✅ 本项目本身不提供交易，文案里彻底不提 |
| ❌ 跨境投资诱导：「港美股开户」「外盘炒」「跨境投资」 | ✅ 若提到美股/日韩行情，只说是「信息展示」，不引导参与 |
| ❌ 制造焦虑/恐吓：「再不买就涨了」「错过这波后悔」 | ✅ 平静陈述工具价值 |

**一句话记忆**：本项目在文案里的定位永远是「**行情信息聚合工具 / 比价工具**」，不是「**投资工具**」。

### 3.3 必带免责声明（每条笔记都要有，可放正文末尾）

> 数据来自公开接口聚合，可能存在延迟或误差，仅供参考，不构成投资建议。

（这是本项目官方 `docs/小红书文案规范.md` 的硬性要求，也是金融类目的保命符。）

### 3.4 导流 / 营销检测红线

- ❌ **站外导流**：个人微信号、手机号、二维码、群号、链接、谐音（VX、威信、微❤等）一律不写。
- ❌ **诱导互动**：不用「点击领取」「点击有惊喜」「私我发你」这类诱导词换互动。
- ❌ **标题党 / 诱导误导**：不用「千万不要点」「不看后悔」式标题。
- ❌ **虚假承诺**：不写「免费送」「无效退款」「零风险」。
- ✅ **商业合规**：若未来走报备 / 蒲公英商业笔记，需专业号资质，推广内容与报备品牌一致（本项目当前以素人笔记为主，暂不涉及）。

### 3.5 其他常见违禁词（扫一眼，写作时避开）

- 承诺类：100% 有效、保证、彻底解决、无副作用、零风险。
- 诱导点击类：点击领奖、卖疯了、抢疯了、再不抢没了、全民疯抢。
- 品牌用语：大牌、王牌、领导者、金牌、遥遥领先。
- 迷信类：招财、旺财、带来好运、逢凶化吉（黄金选题**特别容易**滑向「招财」话术，务必避免）。

### 3.6 限流 / 违规的判断与应对

**限流的典型表现**（区别于正常冷启动）：

- 浏览量（小眼睛）长时间卡在一个数字不涨（如一直卡在几十 / 一两百）；
- 点赞收藏在涨但曝光量停滞；
- 搜索自己的标题 / 关键词找不到自己的笔记；
- 新笔记曝光明显低于同账号历史水平。

**处罚分级**（业界观察，非官方精确口径，供参考）：

| 级别 | 表现 | 应对 |
| --- | --- | --- |
| 初级 | 删内容 + 3 天限流 | 自查违禁词，删改后重发 |
| 中级 | 限流加重、账号降权 | 停更 1–2 周养号，清理可疑旧笔记 |
| 严重 | 封禁 30 天 / 扣信用分 | 走「帮助中心 – 笔记申诉」提交证明材料 |

**自救流程**：先自查 → 删可疑词 → 观察 3–5 天 → 仍未恢复再申诉。**不要**频繁删改重发（反而触发更严审核）。

> 参考来源：违禁词清单 / 审核规则 / 限流判断 / 引流治理，见文末 [参考来源](#八参考来源) ⑩⑪⑫⑬⑭⑮⑯。

## 五、高质量文案生成规范

> 这一节告诉你「怎么让 AI（或你自己）写出能跑量的文案」。生成后**必须**逐项过 3.3 免责声明 + 第七节自查清单。

### 5.1 生成规则（喂给 AI 的约束）

1. **立场**：第一人称「我」，素人视角，口语化、轻快、不端着。
2. **功能描述必须对照第四节清单核实**，禁止编造；数字只写「15 家主流金店」「5 个页面」这类已核实口径。
3. **场景开头**：用一个真实痛点场景开场（挑金饰比价、行情要开好几个网页），不要上来就罗列功能。
4. **结构**：开头钩子 → 适用人群一句 → 亮点分点（短句 + emoji +「·」）→ 细节加分（免费、无广告、深浅主题）→「实在话」局限 + 免责声明。
5. **先种草后降温**：必写 1–2 条真实局限，增强可信度、规避「硬广」判定。
6. **代拟内容标注**：凡「我用了多久」「朋友推荐」「删了别的 APP」等主观体验，交付时标注「代拟，发布前请按真实情况改写」。
7. **去投资化措辞**：全篇避开 3.2 的金融红线词，用「看行情」「比价格」替代「投资」「理财」「收益」。
8. **无法核实项提醒**：小程序是否已上架、搜一搜名称、数据实时性——交付时明确提醒用户确认。

### 5.2 标题公式

- **黄金比价向**：`买金前先比价！{卖点}` / `金价一天一个价，{场景}` / `挑金饰别急着买，先看 {数字} 家金店`
- **全球行情向**：`一个小程序，看全球指数、日韩行情和金价` / `看行情不用下 APP，{数字} 个页面就够了`
- 备选 3–4 个，避开极限词，18–20 字内。

### 5.3 交付物结构（每次生成必须包含）

```
一、标题备选（3–4 个）
二、正文（含：开头钩子 / 亮点分点 / 实在话 + 免责声明）
三、话题标签（8–12 个，分层）
四、配图建议（3 张：封面 + 2 配图，注明截图区域）
五、发布前确认事项（代拟标注 + 无法核实项提醒）
六、自查清单（对照第七节）
```

## 六、生图提示词生成规范

> 用于 AI 生图（ChatGPT / 即梦 / Midjourney 等）制作小红书封面 / 配图。核心目标：**0.5 秒让人看懂卖点 + 高点击率**。

### 6.1 生图提示词通用模板

```
Xiaohongshu cover image, vertical 3:4. [主体：手机屏幕/生活场景/实物特写],
[画面内容：界面分区 + 关键元素 + 配色], [氛围/风格：质感关键词],
[文字：压图大字标题，内容 + 颜色 + 光效], [约束：比例/清晰度/无水印/无真实logo/数字为示意],
[合规约束：不用涨跌/收益/招财类文字].
```

### 6.2 正向词（提升质感，可按需组合）

`premium fintech aesthetic / frosted glass (玻璃拟态) / dark navy background (#0f1a2e) / glowing blue accent / crisp sans-serif numbers / clean composition / high detail / red-up green-down (红涨绿跌) / soft studio lighting / shallow depth of field (浅景深) / photorealistic lifestyle photography`

### 6.3 负向词（避免崩图 + 合规）

`no watermark / no real brand logos / no blurry text / no distorted hands / no extra fingers / placeholder numbers (数字为示意) / no financial promises / no stock-buying advice`

### 6.4 必带三条硬约束（每次都要写进提示词）

1. **`vertical 3:4`**：小红书封面 / 配图标准竖版比例。
2. **`no watermark, no real brand logos, all numbers are illustrative placeholders`**：不画真实品牌 logo，行情数字只作示意，不冒充真实数据。
3. **合规**：封面文字不用「稳赚 / 必涨 / 抄底 / 招财」等诱导词（金融类目 + 黄金「招财」迷信词双红线）。

### 6.5 中文乱码的处理

AI 生图里中文标题经常出乱码。**更稳的做法**：让 AI 生成**无文字版**（提示词写 `no text, clean empty space at top`），
再用美图 / 醒图 / Canva 手动叠加中文标题文字。文字越简单越好（4–8 个字）。
