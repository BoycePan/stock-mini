# TabBar 四行情页接口文档（迁移用）

> **用途**：将本小程序（市场追踪助手）TabBar 中 4 个行情页（全球 / 日韩 / 有色 / AI）所依赖的全部外部 HTTP 接口整理为「入参 / 出参 / 场景 / 解析规则」文档，供迁移到其他程序（H5 / App / 其他小程序 / 后端聚合服务）时直接参考。
>
> **来源**：`src/` 还原源码（2026-08-17 核对，与 `src/utils/api.js`、`src/utils/quote.js`、`src/utils/market-session.js`、`src/utils/jump-mp.js` 及各页面 JS 逐项对齐）。
>
> **说明**：`app.json` 中 tabBar 实际配置 5 个页面，本档覆盖其中 4 个行情页。

---

## 一、总览

### 1.1 页面 → 接口矩阵

| 页面 | pagePath                      | 主要外部接口                | 刷新时机                                          |
| ---- | ----------------------------- | --------------------------- | ------------------------------------------------- |
| 全球 | `pages/global/global`         | ①腾讯 ②新浪 ③东财 ④东财列表 | `onLoad` 一次 + 下拉刷新（`onShow` 不刷行情）     |

## 二、行情接口详述（入参 / 出参 / 字段）

### ① 腾讯行情 `GET https://qt.gtimg.cn/q=<codes>`

**入参**

| 参数    | 说明                                                                                              | 示例                                                     |
| ------- | ------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| `codes` | 逗号分隔的行情代码。前缀规则：`sh`/`sz`（A股）、`kr`（韩股）、`jp`（日股）、`us`（美股）、`fx` 等 | `sh000001,sz399001,usQQQ,usSPY,kr005930,jp8035,sh603993` |

**出参**：纯文本，每个代码一行 `v_<code>="name~code~…~";`，字段以 `~` 分隔。取固定索引：

| 索引   | 含义               | 备注                                                              |
| ------ | ------------------ | ----------------------------------------------------------------- |
| `[1]`  | 名称 name          |                                                                   |
| `[3]`  | 现价 latestPrice   |                                                                   |
| `[4]`  | 昨收 previousClose |                                                                   |
| `[5]`  | 今开 open          |                                                                   |
| `[6]`  | 最高 high          |                                                                   |
| `[7]`  | 最低 low           |                                                                   |
| `[8]`  | 成交量 volume      |                                                                   |
| `[9]`  | 成交额 amount      |                                                                   |
| `[30]` | 行情时间 time      | 数字秒/毫秒、`yyyyMMddHHmmss` 或 `yyyy-MM-dd HH:mm:ss` 均可被解析 |
| `[31]` | 涨跌额 change      | 缺失时按 `现价-昨收` 反推                                         |
| `[32]` | 涨跌幅 pct（%）    |                                                                   |

**解析要点**

- 用正则 `v_<code>="([^"]*)"` 提取；`fields.length < 35` 视为失败。
- 响应含 `pv_none_match`（如空代码）时拒绝。
- 涨跌幅 `|pct| >= 80` 视为异常数据（日韩/非金属解析中丢弃）。
- 本页逻辑中 A 股市场（市场号 0/1）一律走此接口（见 `api.fetchQuoteBySecid`）。

### ② 新浪行情 `GET https://hq.sinajs.cn/list=<keys>`（备选 `?list=`）

**入参**

| 参数   | 说明                                                                                                                                               | 示例                                                              |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| `keys` | 逗号分隔的品类 key：`hf_*`（贵金属）/ `nf_*`（非金属）/ `znb_*`（指数）/ `gb_*`（美股）/ `DINIW`（美元指数）/ `fx_*`（外汇）/ `int_nikkei`（日经） | `hf_GC,hf_SI,nf_AU0,znb_KOSPI,gb_TLT,DINIW,fx_scnykrw,int_nikkei` |

**出参**：纯文本，每行 `hq_str_<key>="<字段,逗号分隔>";`。字段含义**按品类不同**：

| 品类              | 现价  | 昨收/涨跌                  | 说明                                                                                                                                                   |
| ----------------- | ----- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `hf_` 贵金属      | `[0]` | `[7]`                      | 黄金 `hf_GC`/`hf_XAU`、白银 `hf_SI`/`hf_XAG`、铜 `hf_HG`、天然气 `hf_NG`、原油 `hf_OIL`、铝 `hf_AHD`、锌 `hf_ZSD`、镍 `hf_NID`、锡 `hf_SND`、钨 `hf_W` |
| `nf_` 非金属      | `[8]` | `[10]`                     | 沪金 `nf_AU0`/`nf_AU`、沪银 `nf_AG0`/`nf_AG`、沪铜 `nf_CU0`/`nf_CU`、铝/锌/镍/锡同类                                                                   |
| `znb_` 指数       | `[1]` | `[2]`=涨跌额、`[3]`=涨跌幅 | `znb_KOSPI`/`znb_KOSDAQ`/`znb_TOPIX`/`znb_VNINDEX`/`znb_SENSEX`/`znb_VIX`                                                                              |
| `diniw` 美元指数  | `[1]` | `[7]` 或 `[3]`             | 美元指数 `DINIW`                                                                                                                                       |
| `gb_` 美股        | `[1]` | 见下方分消费方说明         | `gb_TLT` 等                                                                                                                                            |
| `fx_` 外汇        | `[1]` | `[3]`                      | 新浪自带 `[10]`=涨跌幅(%)、`[11]`=涨跌额；缺失时由 `(现价-昨收)/昨收` 反推（日韩页汇率）                                                               |
| `int_nikkei` 日经 | `[1]` | `[2]`、`[3]`               | 日经 225（与 `znb_` 同构解析）                                                                                                                         |

**`gb_` 美股字段的分消费方差异（迁移时注意）**

- 全球页行业板块美股代理（`fetchUsProxyChangeMap`）：取 `[2]` 作为涨跌幅。
- 全球页宏观资产（`quote.js` 的 `sina_gb`）：`[1]`=现价、`[2]`=昨收、`[3]`=涨跌幅；涨跌幅缺失时从末尾 8 个字段中取首个 `|值|<80` 的数字。
- `api.fetchStockQuote`（当前页面未调用）：`[0]`=名称、`[1]`=现价、`[2]`=涨跌幅、`[3]`=时间、`[4]`=涨跌额。

**解析要点**

- 正则 `hq_str_<key>="([^"]*)"` 提取；请求失败返回空串，由调用方兜底。
- 新浪接口对 Referer 有校验，必须带 `Referer: https://finance.sina.com.cn`。

### ③ 东财个股行情 `GET https://push2delay.eastmoney.com/api/qt/stock/get`

**入参**

| 参数     | 说明                                                                                                                                                                                                                          | 示例      |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- |
| `secid`  | `市场号.代码`：`1.000001`(上证)、`0.399001`(深成)、`105.QQQ`/`106.`/`107.`(美股)、`100.NDX`/`100.VIX`/`100.UDI`/`100.KS11`/`100.N225`(指数)、`116.005930`(韩股)、`151.8035`(日股)、`119.CNYKRW`(汇率)、`90.BK1134`(板块，走④) | `105.QQQ` |
| `fields` | **短**：`f43,f44,f45,f46,f47,f48,f50,f57,f58,f60,f86,f107,f152,f169,f170`（`fetchQuoteBySecid` 用）；**长**：追加 `f116,f117,f162,f167,f168`（`fetchStockQuote` 用，当前页面未调）                                            | —         |

**出参**：JSON `{ data: { f43, f44, f45, f46, f47, f48, f57, f58, f60, f86, f107, f152, f162, f167, f168, f169, f170, f116, f117 } }`

| 字段                     | 含义                        | 换算                                      |
| ------------------------ | --------------------------- | ----------------------------------------- |
| `f57`                    | 代码 code                   | 原样                                      |
| `f58`                    | 名称 name                   | 原样                                      |
| `f43`                    | 现价                        | `÷ 价格除数`                              |
| `f44` / `f45` / `f46`    | 最高 / 最低 / 今开          | 同上                                      |
| `f60`                    | 昨收                        | 同上                                      |
| `f169`                   | 涨跌额                      | 同上                                      |
| `f170`                   | 涨跌幅                      | `÷100`（百分数）                          |
| `f86`                    | 行情时间戳（秒）            | `×1000` 转毫秒；缺失或距今 >4h 视为 stale |
| `f107`                   | 市场号                      | 116=港股、0=深市、1=沪市、其余=美股       |
| `f152`                   | 价格精度                    | 价格除数 = `10^(f152                      |     | 2)`；**港股（f107=116）恒除 1000** |
| `f47` / `f48`            | 成交量 / 成交额             | 原样                                      |
| `f162` / `f167` / `f168` | PE / PB / 换手率（长字段）  | `÷100`                                    |
| `f116` / `f117`          | 总市值 / 流通市值（长字段） | 原样                                      |

**解析要点**

- `data.f57` 或 `data.f58` 为空即抛「行情为空」。
- 归一化出参结构：`{ secid, code, name, marketName, latestPrice, previousClose, open, high, low, change, changePercent, volume, amount, quoteTimestamp, quoteTime, isStale, source:'东方财富行情' }`。
- 市场 0/1 的 A 股代码不会走到本接口（`fetchQuoteBySecid` 对市场 0/1 直接改走①腾讯）。

### ④ 东财列表行情 `GET https://push2delay.eastmoney.com/api/qt/ulist.np/get`

**入参**

| 参数                   | 说明                                                  | 示例                                           |
| ---------------------- | ----------------------------------------------------- | ---------------------------------------------- |
| `ut` / `invt` / `fltt` | 固定参数（与示例 URL 一致即可）                       | `fa5fd1943c7b386f172d6893dbfba10b` / `2` / `2` |
| `secids`               | 逗号分隔：`90.BK1134`(A股板块)、`105.NVDA` 等美股代理 | `90.BK1134,90.BK1128,105.NVDA`                 |
| `fields`               | 固定 `f12,f13,f3`                                     | —                                              |

**出参**：JSON `{ data: { diff: [ { f12:代码, f13:市场号, f3:涨跌幅 }, … ] } }`

**归一化出参（迁移时直接复用）**

- map，**同时含完整 secid 与裸代码两个 key**：`{ "105.NVDA": 涨跌幅, "NVDA": 涨跌幅, "90.BK1134": 涨跌幅, "BK1134": 涨跌幅 }`。
- 两个消费函数同构：
  - `fetchAShareBoardChangeMap(codes)`：入参为板块代码数组（`['BK1134',…]`），自动补 `90.` 前缀；
  - `fetchUsProxyChangeMap(proxies, mode)`：入参为带市场号的代理股数组（`['105.NVDA',…]`），**新浪优先**（市场 100/105/106/107 先取新浪 `gb_` 涨跌幅），东财 ulist 兜底合并；`mode`（pre/post/regular/live）仅作会话提示，不改变取数策略。

### ④c 东财平均股价指数 `GET https://push2delay.eastmoney.com/api/qt/ulist.np/get?fltt=2&fields=<fields>&secids=47.800005`

- **用途**：全球页「A股平均股价」卡片——东财官方平均股价指数（市场号 47，secid `47.800005`，通达信 880003 口径，全市场等权平均）。**取数链首位（用户指定接口）**。
- **入参**（用户指定 URL，未带 `ut`）：

| 参数     | 说明                          | 示例                                                             |
| -------- | ----------------------------- | ---------------------------------------------------------------- |
| `fltt`   | 2 = 价格/涨跌幅十进制数       | `2`                                                              |
| `fields` | `f17,f18,f8,f15,f12,f16,f115,f2,f14,f5,f6,f3,f20,f13,f145,f100,f265,f266` | — |
| `secids` | 平均股价指数 secid            | `47.800005`                                                      |

- **出参**：JSON `{ data: { diff: [ { f12:代码, f13:市场号, f14:名称, f2:最新价, f3:涨跌幅(%), f18:昨收, … } ] } }`（`fltt=2` 下 f2/f3/f18 均为十进制数，无需再 ÷100）。
- **解析**（`front/utils/quote-parser.ts::parseEastmoneyAveragePrice`）：取 `data.diff[0]`，`f2` → 最新价（缺省返回 null）、`f3` → 涨跌幅、`f18` → 昨收、`f14` → 名称；封装于 `front/api/quote.ts::fetchEastmoneyAveragePrice(secid)`。
- **取数链**（`front/api/market.ts::resolveAShareAveragePrice`）：①东财平均股价指数 → ②腾讯 `sh880003`（与全球指数同批请求，零额外请求）→ ③新浪 `sh880003` → ④东财全市场等权自算（60s 缓存）。任一路给出有效价格即采用（价格 >0 且涨跌幅非异常）；全部失败返回 null（卡片显示 `--`）。
- **域名白名单**：`push2delay.eastmoney.com` 已在生产合法域名内（东财系列接口共用）。

### ⑥ 金价（金投网 jijinhao） `GET https://api.jijinhao.com/quoteCenter/realTime.htm?codes=<JO_代码>`

- **用途**：
  - **金店金价**：金店足金饰品**零售价**（元/克）——周大福/老凤祥/周生生/六福/菜百/中国黄金等 42 家品牌，由 `front/config/gold-shop.ts` 目录维护品牌→品类→JO_ 代码映射（源自金投网实物黄金价格页 `https://quote.cngold.org/gjs/swhj.html`）。
  - **实物黄金价格**：上海黄金交易所现货（黄金9999 Au99.99 基准价/黄金9995/金条100g/黄金T+D/铂金9995/白银T+D 等 8 品种），由 `front/config/physical-gold.ts` 维护（源自 `https://quote.cngold.org/gjs/jjs.html`）。
- **入参**：`codes` = 逗号分隔的 JO_ 代码（金店约 99 个见 `goldShopAllCodes()`；SGE 8 个见 `physicalGoldCodes()`）。
- **Referer 校验（关键）**：不带 Referer 或非白名单来源返回 **HTTP 666**；白名单为 `cngold.org` / `servicewechat.com` 来源。微信 wx.request **自动携带** `Referer: https://servicewechat.com/{appid}/{version}/page-frame.html`，恰好命中白名单，故小程序**可直连**，无需后端代理。迁移到 H5/其他端时需自设 Referer。
- **出参**：JSONP 文本 `var quote_json = {"flag":true,"JO_42660":{...},"errorCode":[]}`（content-type 为 text/html）。解析：取 `quote_json = ` 后的 `{...}` 整体 `JSON.parse`。
- **字段（每条）**：

| 字段          | 含义               | 说明                                                                                            |
| ------------- | ------------------ | ----------------------------------------------------------------------------------------------- |
| `q63`         | 当前价             | 黄金/铂金 元/克；白银 元/千克                                                                   |
| `q70` / `q80` | 涨跌额 / 涨跌幅(%) | **不保证提供**（快照常为 0），前端按「为 0 隐藏涨跌徽标」处理                                   |
| `unit`        | 单位               | `元/克` / `元/千克`                                                                             |
| `time`        | 行情时间戳         | epoch 毫秒                                                                                      |
| `showName`    | 品类名             | 如 黄金价格 / 黄金9999（部分品类名很长，如中国黄金零售价，展示标签请用目录品类名而非 showName） |

- **展示**：有色页末尾新增「金店金价」+「实物黄金价格」两个分区，每行一个品牌/品种，失败自动隐藏该分区、不影响整页行情；实物黄金按配置区间校验价格（防异常快照），白银等非「元/克」品种加单位标签。
- **缓存**：无本地缓存（上游 60s 级快照，页面走 store 缓存 + 5s onShow 刷新逻辑）。
- **域名白名单**：生产环境需在微信公众平台将 `api.jijinhao.com` 加入 request 合法域名。

## 四、各页面调用场景（请求序列 / 标的配置）

### Tab 1｜全球页 `global.js`

**触发场景**：`onLoad` 首屏全量 1 次 → `onShow` 不刷行情 → 下拉刷新重复全量。无定时器。极端时段实时会话与时钟会话不一致时补一次全量刷新。

**一次全量刷新的请求序列**

| 步骤 | 请求                                                                                                                                                  | 入参                                                                                                                                                                                                                                                                  | 说明                                                                           |

## 五、公共逻辑（迁移时需复刻）

### 5.1 多源共识聚合 `quote.fetchAccurate(sources, ctx, opts)`

- **流程**：并行请求前 `parallel` 个源 → 归一化 + 区间/自定义校验 → 「共识」聚合：彼此**相似**（绝对差或相对差 ≤ 容差）的报价归并取**中位数**，组数 ≥2 才合并；不足则逐个补拉剩余源。
- **相似判定**：`absDiff ≤ absTol` 或 `absDiff/max(|a|,|b|) ≤ relTol`，或涨跌幅差 ≤ `pctTol`。
- **来源优先级**（作基准源排序）：`sina_hf/sina_nf/sina_znb/sina_diniw`(1) → `sina_ashare/sina_gb/tencent`(2) → `em`(4) → `stock`(5)。
- **归一化**：`{ price, change, pct, source }`；pct 缺失按 `change/昨收` 反推；`|pct| > 80` 视为异常返回 null。
- `fetchFromSources`：串行取第一个有效报价；`fetchMetricAccurate`：`fetchAccurate` 别名（`parallel=2`）。

### 5.2 市场会话判定 `market-session.js`

- **纯时钟会话**（`getMarketSession` / `getNonferrousMarketSession`）：按北京时间 + 美东夏令时表（3 月第二个周日 ~ 11 月第一个周日）判定 A股盘中/午休/待盘前、美股盘前/盘中/盘后、有色内外盘等阶段。
- **实时会话**（`resolveGlobalMarketSession` / `resolveNonferrousMarketSession`）：并发拉 8 路 / 4 路行情，跟踪价格「活跃度」（是否变动 + 时间戳新鲜度，90min 陈旧阈值），修正时钟判定的开闭状态；**30s 内存缓存 + in-flight 去重**。
- 产出阶段对象：`{ phase, useA, useUs, usMode, label, shortLabel, badgeLabel, industryHint, statusClass }`，供页面展示状态徽标与选择数据源（A 股时段走东财板块，非 A 股时段走美股代理）。

## 六、迁移注意事项（踩坑清单）

1. **文本响应**：①腾讯、②新浪返回的是**非 JSON 文本**（`v_code="…"` / `hq_str_key="…"`），必须用正则按 `~` / `,` 拆分，字段索引固定。
2. **Referer 校验**：新浪接口必须带 `Referer: https://finance.sina.com.cn`，否则可能拒绝；腾讯建议带 `Referer: https://qt.gtimg.cn`。浏览器/H5 迁移注意 CORS，需服务端转发或加代理。
3. **价格精度**：东财 `f43` 等价格字段是整数，须按 `10^(f152||2)` 除（港股 f107=116 恒除 1000）；新浪/腾讯字段已是小数。
4. **汇率特例**：日韩页东财汇率回退价 `/100`（119 汇率精度为 10^4）；新浪汇率用自带涨跌幅 `[10]`/`[11]`（缺失时反推），仅 `|pct| >= 80` 视为无数据。
5. **数据校验**：指数价格须落在合理区间（见日韩页），涨跌幅 `|pct| ≥ 80` 丢弃，避免错源数据污染展示。
6. **市场号路由**：`fetchQuoteBySecid` 对市场 0/1（A 股）走腾讯，其余市场走东财 `stock/get`——迁移时按同一规则选源。
7. **AI 页标的池**：当前还原版为空（`[]`），迁移时需自行补齐产品（A 股）与设备（美股）标的清单，再套用 `fetchAShareMulti` / `fetchUsMulti` 聚合逻辑。
8. **板块映射**：A 股板块 secid 固定 `90.BKxxxx`；美股代理股带 `105./106./107.` 市场前缀，同一代码可能出现在不同市场号下（如 `105.SMCI` 与 `106.VST`），迁移时**不要把前缀当代码本身**。
9. **响应字段稳定性**：东财 `ulist` 的 `f12/f13/f3`、`stock/get` 的 `f43/f57/f58/...` 为公开字段名，建议迁移后加字段级快照校验。
