## 四、共性规律分析（写文直接可抄的结论）

### 1. 高浏览标题的钩子词（出现频次统计）
| 钩子 | 出现标题 | 表现 |
| --- | --- | --- |
| 「不用下APP / 不装APP」 | #2(1027)、#3(979)、#10(339)、#13(169) | 命中率高，是账号最强承诺词 |
| 「实时 / 夜盘 / 国外分时」 | #1(1132)、#6(574)、#10(339) | 美股时段差异化卖点，头部流量 |
| 「金价 / 金店 / 实物金」 | #2(1027)、#4(725)、#11(237)、#20(10) | 金价主题整体强，但「换算」类表述弱 |
| 「一屏看 / 一个页面看齐 / 串起来」 | #2、#3、#5(580)、#13、#18(36)、#19(32) | 「一屏聚合」是核心卖点，需搭配强主题词 |
| 「挖到个神器 / 收藏级 / 挺省事」 | #4(725)、#6(574)、#7(558) | 口语化惊叹式，转化好、互动率高 |
| 「免费」 | #1(1132)、#13(169)、#15(103)、#19(32) | 单独用效果一般，需配「实时国外」等强词 |
| 问句 / 悬念 | #5(580)、#8(461)、#12(234) | 「还要下几个APP？」效果好，蹭热点问句一般 |
| 场景词（通勤 / 早上看盘前） | #8(461)、#9(438) | 稳定中游，稳妥不出错 |

### 2. 选题热度排序（以头部命中率计）
1. **金价 / 黄金**：#2、#4 双头部（1027 / 725），账号第一主题。
2. **日韩 + 美股**：#3(979)、#10(339)、#12(234) —— 日韩美股组合命中率稳。
3. **美股实时 / 外围**：#1(1132)、#6(574)、#8(461) 头部强；但「看懂外围」这种名词罗列式标题（#18，36）失败。
4. **综合一屏看**：#5(580)、#9(438)、#7(558) 中上，靠「少装APP / 省事」角度取胜；纯功能罗列（#13、#19）平淡。
5. **表现弱选题**：A股板块（#16，66）、财经快讯（#17，36）、冷门小金属（#14，109）、金价换算（#20，10）。

### 3. 封面点击率 vs 内容时长（两层漏斗）
- **流量上限看封面/标题**：#1 点击率 31.5% 全站最强（超 93% 同类）→ 浏览 1132 最高。
- **留存看内容**：#3 平均观看 29.4 秒全站最长（正文有干货）→ 浏览 979。
- **反例**：#8 点击率 19.7% 不低，但平均观看仅 6.6 秒（最短）→ 标题强、正文弱，点进来就走。
- 启示：**高点击率标题 + 有信息量的正文**（金店比价、日韩个股列表、时段场景）才能同时拉高浏览与互动。

### 4. 发布时间与长尾
- 头部笔记集中在 **08-21 ~ 08-25 发布**（#1~#5 共 5 篇），发布满一周后仍有持续增长；
- **08-27 之后发布的 8 篇全部 < 340**（还在爬升期，勿过早判死，但已与同龄头部拉开差距）；
- 置顶 2 篇发布最早（08-21），说明早期内容质量最高、值得置顶沉淀。

### 5. 置顶笔记的启示
两篇置顶（#4 金价 725、#7 分享一个看行情 558）均为早期高互动内容；#7 的分享数（7）与互动率（4.5%）全站第一，属「自来水传播」型，标题朴实（「挺省事」）反而引发转发。

## 六、后续写文参考（可直接套用）

### A. 高胜率标题公式（基于 Top5 拆解，均 ≤ 20 字）
1. **「不装APP / 不用下APP」+ 主题词 + 场景**：如「不装APP！金价美股日韩一屏看」（对标 #2/#3）
2. **「挖到个神器 / 收藏级」+ 单一强卖点**：如「挖到个神器！金店金价一页比完」（对标 #4/#6）
3. **反问句 + 痛点**：如「看行情还要装几个APP？」（对标 #5）
4. **时段场景 + 实时承诺**：如「睡前瞄一眼，美股夜盘板块实时看」（对标 #1/#8）
5. **金价主题优先**：#2/#4 证明金价是账号最强自然流量入口，可继续做「金店比价」「金价走势」细分。

### B. 选题优先级建议
- **高优先**：金价/黄金（比价、走势、金店）、日韩+美股组合、「免装APP」承诺、美股实时/夜盘时段场景。
- **中优先**：综合一屏看（务必带「省事/少装APP」角度，勿纯功能罗列）。
- **低优先 / 需重写角度**：A股板块罗列、财经快讯、冷门小金属、「换算」类金价、纯「免费无广告」表述。

### C. 复刻注意事项
1. **正文必须有信息量**（对标 #3 的 29.4 秒）：至少给出可实操的信息，如「42 家金店比价」「日韩个股清单」「盘前看哪几项指标」，避免只夸「好用」导致 6 秒跳出。
2. 标题钩子词前置、带数字/场景/emoji，避开「稳赚/必涨/推荐买入/带你炒股」等合规红线（见 `docs/小红书文案规范.md`）。
3. 高浏览 ≠ 高互动：#1 流量最大但互动率最低（0.8%），说明**导流型笔记要有互动钩子**（提问收尾、评论区引导、收藏点）；#7 证明朴实标题 + 高分享可复制。
4. 新发布笔记存在爬升期，判断选题优劣至少等发布 3-5 天后再下结论。
