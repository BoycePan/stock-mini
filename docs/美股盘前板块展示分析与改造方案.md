## 0. 结论速览

参考项目对「美股盘前板块」的展示方式是：**板块条目本身只有涨跌幅**（无价格），按交易时段自动切换数据源（A 股开市→东财 A 股板块；其余时段→美股代理股涨跌幅均值），并在板块标题右侧挂一个**阶段化胶囊**（如「美股盘前」，橙色系），实时会话还会用行情活跃度校准阶段。

本仓库 `front/` 已经实现了其中绝大部分（板块配置、双数据源、均值聚合、单行布局、分时角标、分享海报），**剩余差距集中在一处数据源窗口差异 + 一处展示增强**：

| 优先级 | 改动 | 一句话说明 | 状态 |
| --- | --- | --- | --- |
| ★★★ 建议改 | 待盘前窗口数据源对齐 | 工作日 15:00–盘前开始（16:00/17:00）参考项目仍展示 A 股板块，本仓库此时已切美股代理股 | ✅ 已实施（2026-08-23，`resolveIndustryUseA`） |
| ★★★ 建议改 | 板块阶段胶囊 | 参考项目显示「美股盘前 / 大A盘中 / 休市」等阶段化徽标（盘前橙、盘中红、盘后蓝、休市灰），本仓库是静态「A股时段 / 美股时段」 | ✅ 已实施（2026-08-23，方案 A：`resolveIndustryPhase`，复用 `marketStatus`/`marketTone`，盘前为 quiet 蓝系） |
| ★★☆ 可选 | 实时会话活跃度追踪 | 参考项目按价格变动 + 时间戳新鲜度判定，本仓库仅时间戳新鲜度 | ⬜ 未实施 |
| ★☆☆ 可选 | 标题文案 | 「全球产业数据」统一标题 vs 本仓库「中国行业板块 / 美股行业板块」切换 | ⬜ 未实施 |

无后端改动；改动 2 若新增配色块必须按 AGENTS.md 主题规范补深色变体。

## 1. 参考项目：盘前板块展示链路

### 1.1 整体数据流

```
市场会话判定（src/utils/market-session.js）
  └─ session = { phase, useA, useUs, usMode, label, shortLabel, badgeLabel, industryHint, statusClass }
        │
        ▼
板块数据加载（src/pages/global/global.js loadIndustryData(session)）
  ├─ useA = true  → api.fetchAShareBoardChangeMap(24 个板块代码)
  │                  东财 ulist.np/get，secids = 90.BKxxxx，fields = f12,f13,f3
  └─ useA = false → api.fetchUsProxyChangeMap(全部 proxies, usMode)
                     新浪 gb_ 优先（市场 100/105/106/107）+ 东财 ulist 兜底合并
                     → 每个板块取「代理股涨跌幅」均值
        │
        ▼
页面展示（src/pages/global/global.wxml + global.wxss）
  ├─ section 标题「全球产业数据」+ ⓘ（说明弹窗）
  ├─ 标题右侧阶段胶囊 .section-session.{{statusClass}}，文本 = industryHint
  └─ sectors-grid 双列网格：icon + name 靠左，arrow + changeText 靠右（up 红 / down 绿 / flat 灰）
```

### 1.2 会话阶段模型（7 阶段，DST 感知）

`market-session.js` 用**北京时间分钟 + 夏令时感知的美股时段表**判定阶段：

| phase | 时段（北京时间） | label | industryHint（板块胶囊） | statusClass（胶囊色） | 板块数据源 |
| --- | --- | --- | --- | --- | --- |
| `ashare` | 工作日 09:30–11:30 / 13:00–15:00 | 大A盘中 | 大A盘中 | `open` 红 | A 股板块 |
| `ashare_lunch` | 工作日 11:30–13:00 | 午间休市 | 午间休市 | `rest` 灰 | A 股板块 |
| `ashare_post` | 工作日 15:00–16:00/17:00 | 待美股盘前 | **休市** | `closed` 灰 | **A 股板块**（关键窗口） |
| `us_pre` | 16:00/17:00–21:30/22:30 | 美股盘前 | **美股盘前** | `pre` 橙 | 美股代理股 |
| `us_regular` | 21:30/22:30–次日 04:00/05:00 | 美股盘中 | 美股盘中 | `open` 红 | 美股代理股 |
| `us_post` | 04:00/05:00–08:00/09:00 | 美股盘后 | 美股盘后 | `post` 蓝 | 美股代理股 |
| `closed` | 其余（周末 / 夜间空档） | 休市 | 休市 | `closed` 灰 | `getClosedDisplayPool()`：工作日 09:30–盘前开始→A，否则 US |

夏令时时段表（`getUsDstSchedule`，分钟制）：

| 时制 | preStart | preEnd | regularStart | regularEndNext（次日） | postStart | postEnd |
| --- | --- | --- | --- | --- | --- | --- |
| 夏令时（3 月第 2 个周日 ~ 11 月第 1 个周日） | 960（16:00） | 1290（21:30） | 1290 | 240（04:00） | 240 | 480（08:00） |
| 冬令时 | 1020（17:00） | 1350（22:30） | 1350 | 300（05:00） | 300 | 540（09:00） |

> 注意 `ashare_post`（待美股盘前）：A 股 15:00 收盘后到美股盘前开始前这 1~2 小时，参考项目**仍展示 A 股板块收盘涨跌幅**（useA=true），板块胶囊显示「休市」。

### 1.3 板块数据源选择（`resolveIndustryUseA`）

```js
// market-session.js
function resolveIndustryUseA(session) {
  if (phase 属于 ashare / ashare_lunch / ashare_post) return true
  if (phase 属于 us_pre / us_regular / us_post)       return false
  if (phase === 'closed') return getClosedDisplayPool() === 'A'  // 工作日 09:30–盘前开始 → A，否则 US
  ...（兜底时钟窗口）
}
```

- **A 股板块**：东财板块行情（`90.BKxxxx`），即 A 股盘面口径；
- **美股代理股**：每个板块配置一组美股代理股（如 AI 算力 → NVDA/AMD/AVGO/MRVL/SMCI），取可命中股票的涨跌幅**算术平均**作为板块涨跌幅；
- `fetchUsProxyChangeMap(proxies, mode)` 的 `mode`（pre/post/regular/live）仅作会话提示入参，**不改变取数策略**。

### 1.4 板块配置（`INDUSTRY_ITEMS`，24 项）

```js
{ code: 'BK1134', name: 'AI算力', icon: '🧠', aSecid: '90.BK1134',
  proxies: ['105.NVDA', '105.AMD', '105.AVGO', '105.MRVL', '105.SMCI'] }
```

每个板块 = `code`（东财板块码）+ `name` + `icon` + `aSecid`（A 股板块 secid）+ `proxies`（带市场号的美股代理股，105=纳斯达克 / 106=纽交所 / 107=美交所）。

### 1.5 页面展示细节

- **阶段胶囊**（`global.wxml` 第 58 行）：`<text class="section-session {{sessionStatusClass}}">{{industrySessionHint}}</text>`，四色分级：
  - `open` 红（盘中）、`pre` 橙（盘前）、`post` 蓝（盘后）、`closed`/`rest` 灰（休市/午休）；
  - 深色主题有配套变体（`.page.theme-dark .section-session.*`）。
- **板块网格**：双列卡片，条目 = `{ icon, name, changeText, toneClass, arrow }`，**只有涨跌幅、无价格**。
- **分享卡片**：Canvas 绘制，行业板块按 4 列网格排版（`_drawShareCard`）。
- **实时会话**（`resolveGlobalMarketSession`）：并发 8 路行情（东财 1.000001 / 0.399001、105.QQQ / 100.NDX + 腾讯 sh000001 / sz399001 / usQQQ / usSPY），按价格活跃度修正时钟阶段：
  - 首次观测 400ms 后重拉双重确认；
  - `trackPrice` 状态机：价格变动 ≥0.01 → live；稳定期距上次变动 <90s（A 股 45s）仍算 live；
  - 时间戳新鲜度 90min 陈旧阈值；盘中行情陈旧 → 降级休市；休市阶段行情活跃 → 升为开盘阶段；
  - **时钟处于美股盘前/盘后时不允许降级为休市**；
  - 30s 内存缓存 + in-flight 去重；结果写入 `globalData._globalLiveSession`，与时钟阶段不一致（极端时段）时页面补一次全量刷新。

## 3. 改造方案（改动清单）

### 改动 1（★ 建议，数据源对齐）：待盘前窗口仍使用 A 股板块

**背景**：D1。参考项目在 A 股收盘后（15:00）到美股盘前开始前（16:00/17:00）的窗口仍展示东财 A 股板块涨跌幅（昨天收盘口径），本仓库此刻已切美股代理股，导致同一时段展示口径不一致。

**目标**：工作日 15:00 ≤ 北京时间分钟 < preStart（夏令时 960=16:00 / 冬令时 1020=17:00）时，板块数据源保持 A 股板块。

**实现要点**（推荐方案：独立函数，语义显式、可单测、不污染 `session.useA` 的其他消费方）：

在 `front/utils/market-clock.ts` 新增导出（纯时钟逻辑，无网络请求）：

```ts
/** 行业板块是否取 A 股数据源（对齐参考项目 resolveIndustryUseA 语义）。
 *  session 使用结构化字段 useA/useUs 判断；二者一致或缺失时回退纯时钟窗口。 */
export function resolveIndustryUseA(
  session: Pick<MarketSession, 'useA' | 'useUs'> | null,
  now: Date = new Date(),
): boolean {
  if (session && session.useA && !session.useUs) return true
  if (session && !session.useA && session.useUs) return false
  const parts = beijingParts(now)
  const workday = parts.weekday >= 1 && parts.weekday <= 5
  const minutes = parts.hour * 60 + parts.minute
  if (workday && minutes >= 570 && minutes < 900) return true // 09:30–15:00 A 股时段（含午休）
  const preStart = isUsDst(now) ? 960 : 1020
  if (workday && minutes >= 900 && minutes < preStart) return true // 待盘前窗口（对齐 ashare_post）
  return false
}
```

`front/api/market.ts` `getGlobalMarketPage` 中第 158 行 `if (session.useA)` 与第 182/200/201 行改以 `resolveIndustryUseA(session)` 为准（或同步调整 `getMarketSession` 的 `useA` 判定纳入该窗口，二者选一，推荐前者）。

**影响面**：`session.useA` 同时被有色页消费（`getMetalsMarketPage` 第 518/553 行），但有色页走 `resolveNonferrousMarketSession`（独立函数，直用 `getAStockPhase`），不受影响，已确认。

### 改动 2（★ 建议，展示对齐）：板块阶段胶囊

**背景**：D2。用户当前只能看到静态「美股时段」徽标，无法区分「盘前 / 盘中 / 盘后 / 休市」。

**目标**：行业板块 section 标题右侧显示阶段化胶囊：大A盘中 / 午间休市 / 待盘前（休市）/ 美股盘前 / 美股盘中 / 美股盘后 / 休市；盘前橙色、盘中红、盘后蓝、休市灰。

**方案 A（小改动，推荐）**：复用 section-card 已有的 `marketStatus` / `marketTone` 胶囊（`front/components/section-card/index.wxml` 第 10–13 行，已支持 active/quiet/rest 三态渲染）：

1. `front/utils/quote-pages.ts` `buildQuoteGlobalPage`：把 `sectorBadge: string` 语义升级为阶段对象（或新增 `sectorPhase?: { status: string; tone: 'active' | 'quiet' | 'rest' }`），写入 `section.marketStatus` / `section.marketTone`；
2. `front/api/market.ts`：按当前会话映射阶段文案与 tone：

| 会话 | 胶囊文案 | tone |
| --- | --- | --- |
| A 股盘中（morning/afternoon） | 大A盘中 | active |
| A 股午休 | 午间休市 | quiet |
| 待盘前窗口（15:00–盘前开始） | 待盘前 | rest |
| 美股盘前（usMode=pre） | 美股盘前 | quiet |
| 美股盘中（usMode=regular） | 美股盘中 | active |
| 美股盘后（usMode=post） | 美股盘后 | quiet |
| 休市 | 休市 | rest |

> 方案 A 的「盘前」胶囊颜色沿用现有 `quiet`（蓝）系，与参考项目橙色 `pre` 略有差异；若产品要求严格还原四色，走方案 B。

**方案 B（还原度更高）**：新增 `MarketSection.phaseStatus` / `phaseTone`（`'open' | 'pre' | 'post' | 'closed' | 'rest'`）字段，在 `front/components/section-card/` 新增 `.section-phase` 四色样式块 + **深色变体**（对齐参考 `global.wxss` 第 209–255 行的 `open/pre/post/closed` 及 `.page.theme-dark .section-session.*` 覆盖），并把 `sectorBadge` 改为透传阶段对象。

**涉及文件**（方案 A）：`front/api/market.ts`、`front/utils/quote-pages.ts`、`front/utils/market-clock.ts`（如需导出阶段映射辅助函数）、`front/types/market.ts`（如新增字段）；方案 B 另加 `front/components/section-card/index.wxml` + `index.wxss`。

### 改动 3（可选增强）：实时会话活跃度追踪

**背景**：D3。参考项目按价格活跃度（首次 400ms 重拉确认、变动 ≥0.01 判定 live、稳定期 90s/45s 宽限、盘前盘后不降级休市）修正时钟阶段。

**建议**：本仓库当前 90min 新鲜度修正已覆盖主要场景，活跃度追踪属于边界时段（开盘前后几分钟）的精度增强，可单独迭代；如需实施，改造 `front/utils/market-session.ts` 的 `sessionFromProbes`，引入参考项目 `trackPrice` 状态机（模块级价格状态 + 首次观测重拉 + 不降级规则），并为 `market-session.test` 补充用例。

### 改动 4（可选）：标题与文案

参考项目板块标题统一为「全球产业数据」+ 简短 tip（「全球产业数据根据公开产业信息整理，仅供信息参考」）；本仓库为「中国行业板块 / 美股行业板块」+ 更详细的时段说明 tip。保留现有 tip（信息量更大）或对齐参考标题均可，属产品文案决策，非功能差异。
