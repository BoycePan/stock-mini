## 备注

- **首页新增第二个 banner 广告位（纯前端渲染槽位 + 后台配置数据，无 `/api/**` 接口契约变化）**：
  需求：首页「行业板块」卡片**底部**也放一个 banner（原来只有 A股指数卡之后的 `homeTop` 一个）。
  - **前端（渲染槽位）**：
    - `front/components/market-page`：新增 `adLocation2` / `adAfterSection2` 两个属性，
      在 `adAfterSection2` 指定分区卡片之后渲染**第二个** `<ad-banner placement="card">`；
      与第一个槽位（`adLocation` / `adAfterSection`）同构、互不排斥。两个属性默认空串，
      未配置时 `wx:if` 为假 → **组件根本不创建**（不占位、无 MobX 绑定开销、不影响布局）。
    - `front/pages/global/index.wxml`：`adLocation2="homeIndustry"`、
      `adAfterSection2="industry-board"` —— `industry-board` 是首页最后一个分区
      （A股指数 → 美股指数 → 宏观经济 → 行业板块），即行业板块卡片正下方、免责声明之上。
    - 复用 `front/components/ad-banner`：unit-id 仍由 `rootStore.system.configs.adConfig`
      按 location 解析（`utils/ad-config.ts resolveAdUnitId`，校验 `status`），
      未配置 / 未启用 / 配置未就绪返回空串不渲染；圆角卡片与深浅主题样式由该组件自带，无需新增样式。
    - 新增 location 枚举值 `homeIndustry`：前端 location 由 8 个变为 **9 个**
      （`homeTop / homeIndustry / asiaTop / matalsTop / finance / minute-detail /
      finance-detail / us-top100 / industry-all`）。
  - **后台（管理端 `app_config`，`cfg_type='display'`，`:configs` 页面）**：
    `adConfig` 分组（id=20）下两条 `bannerAd` 按端各追加一条 `homeIndustry`（微信广告位
    unit-id 两端不通用，故两端各自新建了一个「原生模板广告」广告位）：
    - id=21（`target = shiChang-tracker`，市场追踪助手 wx2cfd1556edf21a24）：
      追加 `{"unit-id":"adunit-cdee0fa0df5c49ad","location":"homeIndustry","status":true}`
      → 9 条。
    - id=31（`target = hangQing-tracker`，行情追踪助手 wx0ecd2049e54fbca8）：
      追加 `{"unit-id":"adunit-08072b2a4ca17cb7","location":"homeIndustry","status":true}`
      → 9 条。
    - 写入方式：`PUT /api/mgr/configs/{id}`（**部分更新，只传 `cfgValue`**，数组整体覆盖；
      `Authorization: Bearer {admin-token}`，见 docs/API.md 8.4）；写入后复读校验：
      两条均为 9 条、`homeIndustry` 命中对应端 unit-id、**其余 8 条与修改前逐条一致**
      （`enabled` 仍为 true）。
  - **生效方式**：`GET /api/v1/configs?cfgType=display`（docs/API.md 八）**直读库、无缓存**，
    端上下次拉取配置即生效，无需发版；临时下线把该条 `status` 改 `false` 即可（不用删数组项）。
  - **校验**：`tsc --noEmit`、`eslint`、`node --test`（525 个用例）、`prettier --check` 全绿；
    另外用**前端真实解析函数** `resolveAdUnitId` 对线上两条 `bannerAd` 实测：
    `homeIndustry` → 各端返回本端 unit-id，`homeTop` → 仍为原 unit-id，未配置的 location → 空串。
  - **关联文件**：`front/components/market-page/index.wxml`、`front/components/market-page/index.ts`、
    `front/pages/global/index.wxml`、`front/components/ad-banner/index.ts`（location 枚举注释）、
    `docs/广告位配置-原生模板广告.json`（补 `homeIndustry` 映射 + 两端完整 cfgValue，
    文档由原来的单端口径改为两端并列）、
    `docs/微信广告数据每日拉取分析与建表方案.md`（location 枚举 8 → 9）。
