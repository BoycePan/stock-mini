## 备注

- **设置页「开发者选项」入口改为后台配置驱动（纯前端消费改动，无 `/api/**` 接口契约变化）**：
  设置页（`front/pages/settings/index`）「开发者选项」（接口环境切换）入口展示条件由
  `isDev` 调整为 `isDev && userShowEnv`——仅开发版 / 体验版可能展示，且需后台
  `app_config`（`cfg_type='display'`，见 docs/API.md 八）配置开启：
  - 后台需新增**单一配置键 `userShowEnv`**（布尔，缺省关闭，配 `true` 开启）。与
    `homeShowTop100` / `canShowMinute` 的「正式键 + Dev 键」双键模式**不同**，本键无
    `userShowEnvDev` 尾缀——正式 / 开发 / 体验版统一读 `userShowEnv`（各环境同一份配置），
    前端解析不区分环境，入口本身仍由 `isDev` 限定在非线上版本。
  - 解析函数：`front/utils/system-config.ts resolveUserShowEnvEnabled(config)`
    （纯函数，只读 `config.userShowEnv`，缺省 false；便捷版 `isUserShowEnvEnabled()`）——
    与 `createFeatureToggle` 双键工厂不同，该开关为单键读取，故未走工厂；
  - 类型：`front/types/system.ts AppConfig.config` 新增 `userShowEnv` 字段（不新增
    `userShowEnvDev`）；
  - 设置页在 `onShow` 的 `syncNotices`（bootstrap 完成）后按全局配置刷新
    `data.userShowEnv`，配置到达时入口即时出现。
  - 关联文件（前端）：`front/pages/settings/index.{ts,wxml}`、
    `front/utils/system-config.ts`、`front/types/system.ts`、
    `front/tests/system-config.test.ts`。

- **板块列表页（`front/packageQuote/pages/industry-all`）标题 + 广告位调整（纯前端，无 `/api/**` 接口契约变化）**：
  - 顶部标题改为 **logo + 小程序名称**（与首页 header 一致：`app-header` 不再传 `title`，
    `showBrand` 开启，标题兜底展示 appName），不再显示随 Tab 切换的 `headerTitle`
    （`headerTitle` 相关元数据已从 `index.ts` 移除）；当前所属分类由页面内常驻 board-tabs 标识；
  - 在列表滚动区（scroll-view）内**第一个元素新增广告位**（`loading-state` 之前），
    location 为 `industry-all`，`placement="card"`；
  - 该页本地已实现的顶栏「分享海报」入口（`share-poster` 组件 + `posterShare`）在合并后保留，
    与品牌头并存；分享 / 海报文案标题改用固定的分类名（`index.ts` 内 `SHARE_TITLE`）。
- **后端配合项（数据配置，非接口契约变化）**：`industry-all` 是新广告位标识，
  需要后端在 `app_config`（`cfg_type='display'`）的 `adConfig.bannerAd` 中新增一条
  `{ "location": "industry-all", "unit-id": "<流量主广告位ID>", "status": true }`，
  配置到达前前端不渲染该广告位（不影响布局）。
- 关联文件（前端）：`front/packageQuote/pages/industry-all/index.{wxml,ts,json}`、
  `front/types/system.ts`（location 注释）、`docs/微信广告数据每日拉取分析与建表方案.md`（location 枚举）。
