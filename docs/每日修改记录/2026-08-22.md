# 接口修改记录 · 2026-08-22

> 对比基线：`main` → 当前 `dev` 分支

> 内部实现文件仅列在「关联文件」，不影响接口契约的内部重构归入「备注」。

## 一、新增接口

### GET /api/v1/news/needToPull

- **用途**：判断是否需要拉取最新新闻（供客户端增量刷新轮询）。
- **入参**

  | 参数 | 类型 | 必填 | 说明 |
  |---|---|---|---|
  | lastPullTime | long | 否 | 客户端上次拉取时间戳（毫秒），默认 `0` |

- **出参**：`data` 为 `boolean`。服务端新闻更新时间 `UPDATE_TIME > lastPullTime` 时返回 `true`。
- **关联文件**：`controller/NewsController.java`（`needToPull`）、新增 `util/NewsUpdateUtil.java`

### POST /api/mgr/login

- **用途**：管理端登录（简单口令校验）。拼接 `用户名@密码` 后做 base64，与 `app.mgr.admin-token` 比对，一致则返回该 base64 作为后续 `/api/mgr/**` 请求的 `Authorization: Bearer <token>`。
- **入参**（JSON body）

  | 参数 | 类型 | 必填 | 说明 |
  |---|---|---|---|
  | username | string | 是 | 管理员用户名 |
  | password | string | 是 | 管理员密码 |

- **出参**：`data` 为登录成功后的 base64 token（string）；失败返回业务码 `400` + `用户名或密码错误`。
- **说明**：登录接口本身不受 mgr 拦截（拦截器 `excludePathPatterns("/api/mgr/login")`）。
- **关联文件**：`controller/MgrController.java`、`config/MgrAuthInterceptor.java`、`config/WebConfig.java`、`config/AppProperties.java`、`application.yml`、`.env.example`

### RSS 数据源管理（`/api/mgr/rss/**`）

> 管理后台 RSS 新闻源（`rss_source` 表）CRUD + 状态 + 试抓预览。以下接口均需 `Authorization: Bearer <admin-token>`（登录接口返回）。

#### GET /api/mgr/rss/sources

- **用途**：数据源列表。软删源默认不返回，`includeDeleted=true` 时包含。
- **入参**

  | 参数 | 类型 | 必填 | 说明 |
  |---|---|---|---|
  | includeDeleted | boolean | 否 | 默认 `false`；`true` 返回含软删的源 |

- **出参**：`data` 为数组，每项含 `id/name/url/viaWorker/enabled/deleted/lastStatus/lastError/lastFetchAt/lastItemCount`。

#### POST /api/mgr/rss/sources

- **用途**：新增源。
- **入参**（JSON body）

  | 参数 | 类型 | 必填 | 说明 |
  |---|---|---|---|
  | name | string | 是 | 源名称 |
  | url | string | 是 | RSS/Atom feed 地址（`url` 唯一，重复会报错） |
  | viaWorker | boolean | 否 | 默认 `false`，是否走 Cloudflare Worker |
  | enabled | boolean | 否 | 默认 `true`，是否启用 |

- **出参**：`data` 为新增后的完整源对象。

#### PUT /api/mgr/rss/sources/{id}

- **用途**：修改源字段，只传要改的项；启停（`enabled`）、软删（`deleted:true`）、恢复（`deleted:false`）都走这里。
- **入参**（JSON body，均为可选）

  | 参数 | 类型 | 说明 |
  |---|---|---|
  | name | string | 源名称 |
  | url | string | feed 地址 |
  | viaWorker | boolean | 是否走 Worker |
  | enabled | boolean | 启用/停用 |
  | deleted | boolean | `true` 软删，`false` 恢复 |

- **出参**：`data` 为更新后的完整源对象。

#### POST /api/mgr/rss/check

- **用途**：试抓（可达性 + 预览条目）。只读，不写 `news_feed`。
- **入参**（JSON body）

  | 参数 | 类型 | 必填 | 说明 |
  |---|---|---|---|
  | id | long | 否 | 已保存源 id；与 `url` 二选一（都传以 id 为准） |
  | url | string | 否 | 裸 URL 试抓（新增/编辑保存前校验用） |
  | viaWorker | boolean | 否 | 仅 `url` 场景生效，默认 `false` |
  | maxItems | int | 否 | 预览最多条数，默认 `app.rss.max-items-per-feed`(20) |
  | saveStatus | boolean | 否 | 默认 `false`；`true` 且传 `id` 时回写 `last_*` 状态 |

- **出参**：`data` 含 `reachable/status("ok"|"fail")/elapsedMs/itemCount/error/feedTitle/items[]`（items 每项 `title/link/publishedAt`；`feedTitle` 为 feed 真实标题 `<channel><title>`，可达时返回、空串归一为 null，供前端自动填源名称）。
- **关联文件**：`controller/MgrController.java`、`service/RssSourceService.java`、`dao/RssSourceRepository.java`、`model/RssSource.java`、`task/RssNewsScheduler.java`、`external/rss/RssNewsClient.java`、`scripts/rss_source_manage_migration.sql`、`scripts/rss_source.sql`、`src/test/resources/schema.sql`

## 二、修改接口

### GET /api/v1/news/feed

- **变更点**：新增可选查询参数 `keyword`，支持按 **标题（title）+ 内容（summary）** 做模糊搜索，大小写不敏感。
- **入参（新增项）**

  | 参数 | 类型 | 必填 | 说明 |
  |---|---|---|---|
  | keyword | string | 否 | 关键字，命中 `title` 或 `summary` 任一即返回（`LIKE '%kw%'`，`LOWER()` 归一化） |

- **说明**
  - 不传 `keyword`（或空白）时行为与原来一致，返回全量 feed；
  - 只作用于 `stock_code = ''` 的通用新闻（新浪 feed + RSS），个股新闻不受影响；
  - 分页 / `id` 增量过滤逻辑保持不变。
- **关联文件**：`controller/NewsController.java`、`service/NewsService.java`、`dao/NewsRepository.java`

### POST /api/v1/auth/login

- **变更点**：登录成功后把 `user_id` 写入请求上下文（`request.setAttribute("user_id", ...)`），供 `RequestLogFilter` 的访问日志输出 `uid`。
- **说明**：入参 / 出参契约不变，仅增强日志埋点。
- **关联文件**：`controller/AuthController.java`、`service/AuthService.java`
