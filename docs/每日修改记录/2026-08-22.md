## 一、新增接口

### GET /api/v1/news/needToPull

- **用途**：判断是否需要拉取最新新闻（供客户端增量刷新轮询）。
- **入参**

  | 参数 | 类型 | 必填 | 说明 |
  |---|---|---|---|
  | lastPullTime | long | 否 | 客户端上次拉取时间戳（毫秒），默认 `0` |

- **出参**：`data` 为 `boolean`。服务端新闻更新时间 `UPDATE_TIME > lastPullTime` 时返回 `true`。
- **关联文件**：`controller/NewsController.java`（`needToPull`）、新增 `util/NewsUpdateUtil.java`

## 二、修改接口

### GET /api/v1/news/feed

- **变更点**：新增可选查询参数 `keyword`，支持按 **标题（title）+ 内容（summary）** 做模糊搜索，大小写不敏感。
- **入参（新增项）**

  | 参数 | 类型 | 必填 | 说明 |
  |---|---|---|---|
  | keyword | string | 否 | 关键字，命中 `title` 或 `summary` 任一即返回（`LIKE '%kw%'`，`LOWER()` 归一化） |

- **说明**
  - 不传 `keyword`（或空白）时行为与原来一致，返回全量 feed；
  - 只作用于 `stock_code = ''` 的通用新闻（新浪 feed + RSS），个股新闻不受影响；
  - 分页 / `id` 增量过滤逻辑保持不变。
- **关联文件**：`controller/NewsController.java`、`service/NewsService.java`、`dao/NewsRepository.java`

### POST /api/v1/auth/login

- **变更点**：登录成功后把 `user_id` 写入请求上下文（`request.setAttribute("user_id", ...)`），供 `RequestLogFilter` 的访问日志输出 `uid`。
- **说明**：入参 / 出参契约不变，仅增强日志埋点。
- **关联文件**：`controller/AuthController.java`、`service/AuthService.java`
