# 每日修改记录

本目录集中记录后端**对外 HTTP 接口**（`/api/v1/**`）的每日变更：新增了哪些、修改了哪些、删除了哪些。

## 规范

1. **每天一个文件**，文件名 `YYYY-MM-DD.md`（如 `2026-08-22.md`）。
2. 接口每次**新增 / 修改 / 删除**，当天同步写入对应日期的文件。
3. 文件统一按以下分区组织：

   - `## 一、新增接口`
   - `## 二、修改接口`
   - `## 三、删除接口`（如有）
   - `## 备注`

4. 每个接口写明：**方法 + 路径**、用途、入参 / 出参变化、关联改动文件。
5. 只记录对外接口契约变化；不影响接口的纯内部重构归入「备注」。

> 完整接口文档见仓库根目录 `docs/API.md`；本目录只做**增量变更日志**，按天回溯接口演化。
