## 一、新增接口

### 1. 管理端 · 微信广告数据查询

- **方法 + 路径**：`GET /api/mgr/ad/stats`
- **用途**：查询已落库的微信广告日统计（`wx_ad_daily_stat`，端 × 广告位类型 × 天），供管理后台看板/对账。
- **入参（Query，均可选）**：
  - `target`：端（`app.wechat.apps` 的 key，如 `shiChang-tracker`）；空 = 全部端
  - `from` / `to`：统计日期区间（含端点，`yyyy-MM-dd`）
  - `adSlot`：广告位类型枚举（如 `SLOT_ID_WEAPP_COVER`）；空 = 全部类型
- **出参**：`ApiResponse<List<Map>>`，每行字段：
  `id, target, statDate, adSlot, adSlotName, reqSuccCount, exposureCount, exposureRate,
  clickCount, clickRate, incomeFen（分）, incomeYuan（元，2 位小数）, ecpmFen（分/千次）, pulledAt`
- **鉴权**：`/api/mgr/**`，走 `MgrAuthInterceptor`（Bearer admin token）。

### 2. 管理端 · 手动触发广告数据拉取

- **方法 + 路径**：`POST /api/mgr/ad/pull`
- **用途**：手动触发一次广告数据拉取（先刷新 token 再拉，逐端返回拉取行数），联调/补数用，不依赖 9:00~18:00 定时窗口。
- **入参（Query，均可选）**：
  - `from`：起始日期（含，`yyyy-MM-dd`）；缺省 = 近 `lookbackDays` 天
  - `to`：结束日期（含，`yyyy-MM-dd`）；缺省 = 今天
- **出参**：`ApiResponse<Map>`：`{ from, to, totalRows, failed, sources:[{source, rows|error}] }`
- **鉴权**：`/api/mgr/**`，走 `MgrAuthInterceptor`（Bearer admin token）。

## 备注

- 新增「微信广告数据每日拉取」能力（流量主数据，老版 `publisher/stat` 接口已实测可用）：
  - 表：`wx_access_token`（凭证，每端一条）、`wx_ad_daily_stat`（广告日统计）；
  - 任务：`RefreshWxAccessTokenTask`（每 20 分钟刷 token）、
    `PullWxAdDataTask`（每天 9:00 后每 20 分钟、18:00 前结束，拉近 3 天窗口滚动 upsert 覆盖）。
