# 小红书文案写作规范

> 适用场景：用户要求以「用户视角」撰写小红书笔记、推荐本小程序（市场追踪助手）时。
> 本文档与根目录 `AGENTS.md` / `CLAUDE.md` 配合使用，是文案类任务的可执行规范。

## 一、事实与体验的区分（强制）

1. 功能描述必须以仓库代码为准：
   - 写前先核对 `front/config/tabbar.ts`、`front/pages/*`、`front/components/*`、`docs/`；
   - 禁止编造不存在的功能（例：目前**没有**自选股分组、价格提醒、交易功能）。
2. 「用户视角」是代拟叙事：涉及使用时长、个人经历、「删掉了其他 APP」等主观体验，
   交付时必须标注「此段为代拟，发布前请按真实情况改写」，不得默认虚构为事实。
3. 无法核实的信息必须显式提醒用户确认：小程序是否已上架、微信内搜索名称、
   数据实时性与准确性、金店数量等。

## 二、平台合规红线（小红书）

1. 标题 / 正文禁用：稳赚、必涨、保证收益、推荐买入、带你炒股、加微信跟单 等金融诱导表述。
2. 必须保留免责声明：数据来自公开接口聚合、可能存在延迟或误差、仅供参考、不构成投资建议。
3. 截图用中性界面（首页、金价页、深色模式、K 线页），不放单只个股大涨 / 暴跌图诱导跟风。
4. 引流走产品内入口（如「设置 → 问题反馈」），正文不直接放个人微信 / 二维码。
5. 标题不得超过平台 20 字上限（含标点 / emoji / 英文，按平台输入框计法折算，中文每字计 1）。

## 四、文案结构模板

1. **标题**：给 3-4 个备选；**硬性上限 20 个字**（含标点 / emoji / 英文，按平台输入框计法折算，中文每字计 1），
   建议控制在 16-18 字留出余量；关键词（如「免费 / 金价 / A股 / 日韩」）前置；带 emoji / 数字 / 场景钩子；避开合规词。
   例（均 ≤20 字）：「微信小程序挖到宝！A股美股金价一屏看」「免费无广告，全球行情+日韩+金价都有」「宝藏小程序！A股美股金价日韩一网打尽」
2. **正文**：
   - 开头：发现背景（口语化、第一人称）；
   - 适用人群：一句话（看行情 / 比金价 / 刷财经新闻的普通人）；
   - 功能亮点：按板块分组，短句 + emoji + 「·」列表；
   - 细节加分：免费、无广告、深浅主题、下拉刷新等；
   - 「实在话」：主动写 1-2 条真实局限（如暂无自选股分组、无价格提醒、数据可能有延迟）+
     免责声明，增强可信度；
   - 配图建议：3 张（首页、金价页、深色模式），封面用首页加字。
3. **话题标签**：8-12 个，如 #微信小程序 #行情软件 #理财工具 #黄金 #金价 #全球股市 #投资理财
   #财经资讯 #实用小程序 #日常分享

## 五、写作风格

- 第一人称「我」，口语化、轻快、不端着；
- 短段落、短句；多用 emoji 和「·」列表；
- 先种草后降温（结尾提局限），避免「全好评」的营销感；
- 用词准确：区分事实 / 推测 / 主观评价，不夸大、不承诺收益。
