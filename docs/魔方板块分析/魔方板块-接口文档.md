## 3. 接口详情

### A. 东方财富系(eastmoney.com)

#### A1. 实时行情 — `/api/qt/stock/get`

- **Host**: `push2delay.eastmoney.com`(延迟行情;另有 `push2.eastmoney.com` 实时节点)
- **Method**: GET
- **抓包次数**: 1556(全部 200,响应 91~307 B)
- **用途**: 查询单个证券(股票/指数/ETF/期货/汇率)的实时行情快照

**请求示例**

```
https://push2delay.eastmoney.com/api/qt/stock/get?fltt=2&invt=2&secid=100.TWII&fields=f43,f44,f45,f46,f47,f48,f50,f57,f58,f60,f86,f107,f152,f169,f170
```

| 参数 | 必填 | 类型 | 说明 | 示例值 |
| --- | --- | --- | --- | --- |
| `fltt` | 否 | int | 浮点精度标记,2=保留两位小数(价格字段以浮点返回);缺省时价格为放大后的整数 | `2` |
| `invt` | 否 | int | 是否逆转换,2=与 fltt=2 配合 | `2` |
| `secid` | 是 | string | 证券唯一标识:`市场代码.证券代码`(市场代码见附录A) | `100.TWII` |
| `fields` | 是 | string | 逗号分隔的返回字段编码(见附录B f字段字典) | `f43,f44,...,f170` |
| `ut` | 否 | string | 令牌参数,部分调用携带(如 ulist 接口) | `fa5fd1943c7b386f172d6893dbfba10b` |


**实测响应示例**(secid=100.TWII,台湾加权指数)

#### A2. K线数据 — `/api/qt/stock/kline/get`

- **Host**: `push2his.eastmoney.com`(历史主节点)、`push2delay.eastmoney.com`(延迟节点)、`push2.eastmoney.com`、`82.push2his.eastmoney.com`(备用)
- **Method**: GET
- **抓包次数**: 90(其中 **75 次状态码 999 = 连接失败**,仅 push2delay 节点 15 次成功 200)
- **用途**: 查询证券的日/周/月/分钟 K 线

**请求示例**

```
https://push2his.eastmoney.com/api/qt/stock/kline/get?&secid=0.002155&fields1=f1&fields2=f51,f53,f59&klt=101&fqt=0&end=20500101&lmt=1&_t=1787288188250
```

| 参数 | 必填 | 类型 | 说明 | 示例值 |
| --- | --- | --- | --- | --- |
| `secid` | 是 | string | 证券唯一标识(市场代码见附录A) | `0.002155 / 100.SPX` |
| `klt` | 是 | int | K线周期:101=日K,102=周K,103=月K,1/5/15/30/60=分钟K | `101` |
| `fqt` | 是 | int | 复权方式:0=不复权,1=前复权,2=后复权 | `0` |
| `lmt` | 是 | int | 返回K线根数 | `1 / 40` |
| `end` | 否 | string | 截止日期 yyyyMMdd,20500101 表示取到最新 | `20500101` |
| `fields1` | 否 | string | 行情基础字段(如 f1,f2,f3,f4,f5,f6) | `f1` |
| `fields2` | 是 | string | K线数据字段:f51=日期,f52=开,f53=收,f54=高,f55=低,f56=成交量,f57=成交额,f58=振幅,f59=涨跌幅,f60=涨跌额,f61=换手率 | `f51,f53,f59` |
| `iscca` | 否 | int | 跨境/海外行情标记(美股指数调用时=1) | `1` |
| `_t` | 否 | long | 时间戳,防缓存 | `1787288188250` |


**实测响应示例**(push2delay 节点,secid=100.SPX)

**返回结构**

```json
{
  "rc": 0,
  "rt": 17,
  "svr": 177542528,
  "lt": 1,
  "full": 0,
  "dlmkts": "8,10,128",
  "dsc": "0",
  "data": {
    "code": "SPX",          // 证券代码
    "market": 100,          // 市场代码
    "name": "标普500",      // 证券名称
    "decimal": 2,           // 小数位数
    "dktotal": 0,           // K线总根数
    "preKPrice": 0.0,       // 前收盘价
    "klines": []            // K线数组;每行格式见下
  }
}
```


`klines` 数组元素格式(标准东财 K 线,每根一行字符串,逗号分隔 11 个字段):

```
日期,开盘,收盘,最高,最低,成交量,成交额,振幅,涨跌幅,涨跌额,换手率
例:2026-08-20,3890.00,3903.72,3911.08,3883.79,294767139,590670293454.80,0.70,-0.11,-4.10,0.62
```

**抓包观察**:CSV 中 push2his/push2/82.push2his 节点请求全部返回状态码 **999**(连接被重置/反爬拦截),仅 push2delay 节点成功且 `klines` 为空数组(延迟节点不提供历史K线)。**如需完整K线数据,应使用 push2his 节点并在具备合法 Referer/UA 的环境请求**,否则易被拦截。

- **Host**: `push2delay.eastmoney.com`(另有 `push2.eastmoney.com`)

- **抓包次数**: 82(全部 200,响应 213~1750 B)

**请求示例**

```
https://push2delay.eastmoney.com/api/qt/ulist.np/get?&ut=fa5fd1943c7b386f172d6893dbfba10b&invt=2&fltt=2&secids=100.UDI,105.TLT,122.XAU,101.GC00Y,122.XAG,101.SI00Y,113.cum,113.alm,113.znm,113.nim,113.snm,0.000657,1.601958,0.002428,0.000960,0.002155&fields=f12,f13,f14,f2,f3,f4,f60,f86&_t=1787288188145
```

| 参数 | 必填 | 类型 | 说明 | 示例值 |
| --- | --- | --- | --- | --- |
| `secids` | 是 | string | 逗号分隔的多个证券标识 `市场.代码` | `106.TSM,105.ASML,116.09988` |
| `fields` | 是 | string | 返回字段编码:f12=代码,f13=市场,f14=名称,f2=最新价,f3=涨跌幅,f4=涨跌额,f60=昨收,f86=时间戳 | `f12,f13,f14,f2,f3,f4,f60,f86` |
| `fltt` | 否 | int | 浮点精度,2=两位小数 | `2` |
| `invt` | 否 | int | 逆转换标记 | `2` |
| `ut` | 否 | string | 令牌参数 | `fa5fd1943c7b386f172d6893dbfba10b` |
| `_t` | 否 | long | 时间戳,防缓存 | `1787288188145` |


**实测响应示例**(secids=106.TSM,105.ASML,116.09988,fields=f12,f13,f3)

**返回结构**

```json
{
  "rc": 0,

  "svr": 177622161,

  "full": 1,
  "dlmkts": "8,10,128",
```
