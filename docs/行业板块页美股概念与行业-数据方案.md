# 行业板块页 · 美股概念/行业 Tab —— 数据方案与实现说明

> 生成日期：2026-09-08（成分股市场号核对同批完成）
> 范围：仅前端 `front/` 改动；无后端 `/api/**` 接口变更 → 不需写 `docs/每日修改记录/`
> 页面：`front/packageQuote/pages/industry-all/index`（在原 A股「概念板块/行业板块」Tab 旁新增
> 美股概念 / 美股行业 两个 Tab，无新增页面、无新增入口卡）

## 1. 背景：为什么美股没有「全部板块」全量目录

原 A 股「行业板块 / 概念板块」能展示 500+ 全量目录，是因为东财 `clist/get` 对
`fs=m:90+t:2/t:3` 返回**板块行情目录**（BKxxxx + 当日涨跌幅 + 成分股）。

**美股没有等价目录**（2026-09-08 对东财 push2delay 实测）：

- `clist/get` 的 `fs=m:105+t:1/2/3`、`m:106…`、`m:107…` 均只返回**个股列表**，不是板块；
- 美股个股 `stock/get` 只带一个粗粒度 GICS 行业字符串（f127，如 AAPL/NVDA 均为「信息技术」）；
- 新浪 `gb_`、腾讯 `qt.gtimg.cn` 同样只有个股级报价。

因此美股 Tab 采用与**首页「美股行业板块」完全同款的口径**：精选主题/行业目录 +
**美股代表成分股**，板块涨跌幅 = 成分股当日涨跌幅**等权均值**（纯国内公开行情源）。

## 2. 目录数据（`front/config/us-board-catalog.ts`）

- 美股概念 27 项（AI算力 / 减肥药 / 加密货币 / 量子计算 / 中概互联 …）；
- 美股行业 23 项（银行 / 保险 / 半导体设备 / 消费电子 / 公用事业 …）；
- 每项 = `{ code, name, proxies[] }`，proxies 为带市场号的东财 secid
  （105=纳斯达克 / 106=纽交所 / 107=美交所及部分 ETF）。
- **全部 178 个成分 ticker 已逐只经东财 suggest(type=14，返回 QuoteID/MktNum) 实测核对**
  （2026-09-08，全量命中、零缺失），并据此修正了部分市场号（如 SOXX=105、BATT/TAN/ROBO/GDX/
  XLE/REMX/FCG=107、IONQ/OKLO/SMR=106、GSAT/SHOP/ICLR=105 …）。
  ⚠️ `EA`/`GOLD` 在东财 suggest 中会误配到其他标的，已刻意不用。
- 后续**增删板块/成分必须重新过一遍 suggest(type=14) 核对市场号**，勿凭直觉写 105/106。

## 3. 取数（`front/api/us-board-quotes.ts` + `front/utils/us-boards.ts`）

| 环节 | 口径 | 数据源（全部国内） |
| --- | --- | --- |
| 板块行涨跌幅 | 成分股涨跌幅等权均值（`averageBoardPcts`），复用首页同款 `fetchUsProxyChangeMap` | 新浪 `hq.sinajs.cn` `gb_`（现价涨跌幅 [2]）优先；东财 `ulist` f3 兜底 |
| 美股盘前（美东 04:00–09:30，`getUsPhase()==='pre'`） | 只统计「有实时盘前数据」成分，用盘前参考涨跌幅（新浪 `gb_` [22]，[21] 盘前价 / [24] 盘前时间 isToday 判定），无 EM 兜底 | 新浪 `gb_` 盘前字段（与首页盘前口径一致） |
| 成分弹窗 | 每只成分：涨跌幅（同上口径）+ 中文名 + 当日分时 | 东财 `ulist`（f14 中文名 / f3）一次批量 + 新浪 `gb_` 兜底 |
| 点击成分行 | 跳 `minute` 页当日分时（mcode=东财 secid，`EM_US_SECID_RE` 直连，不走外部源） | 东财 `trends2`（minute 页既有链路） |

页面交互（搜索/排序/缓存/下拉刷新/自动保鲜）与 A 股 Tab 复用同一套：搜索支持板块名与
**成分股代码**（如输 `NVDA` 命中 AI算力/半导体）；四类 Tab 均按板块分类模块级缓存，
60s 静默刷新（`loadKind` 分支：A 股走东财全量、美股走目录聚合）。

## 4. 展示与合规

- 美股 Tab 列表同样只有涨跌幅、无价格；列表上方说明文案随 Tab 切换
  （美股 =「美股板块涨跌幅为成分股行情等权聚合（公开行情，可能有延迟），仅供参考，
  不构成投资建议。」），页脚沿用 `disclaimer-footer`；
- 深浅主题：完全复用本页既有 class 与色板，无新增硬编码色（本次不动 wxss 主题规则）；
- 成分中文名来自东财 f14（UTF-8 JSON，直接可读），个别未收录时回退裸代码。
