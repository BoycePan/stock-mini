## 0. 结论速览（推荐组合）

| 数据模块 | 推荐主源 | 备用源 |
|---|---|---|
| 全球经济数据（原油/VIX/美元/美债/金银铜/天然气） | 新浪财经 `hq.sinajs.cn` | 腾讯行情、雅虎 |
| 全球产业数据（美股板块涨跌） | 腾讯 `qt.gtimg.cn`（美股/ETF） | 新浪 `gb_*`、雅虎 |

| 有色（金银/工业金属） | 新浪国内期货 `nf_*` / COMEX `hf_*` | 雅虎 LME |
| 小金属现货（钨钼锑铟锂） | 长江有色金属网（HTML 日频） | 同花顺"小金属概念"板块涨跌幅 |
| AI 产业指数 / 热门概念 | 同花顺概念板块（后端已接入） | 东方财富 BK 概念板块 |
| 股票/板块/新闻/公告 | 后端已有（新浪/同花顺/巨潮） | — |

**通用结论：**
1. 所有推荐源均**免费、无 API Key、无官方注册要求**。
2. 实测高频压测（新浪/腾讯 30 连发、雅虎 10 连发）全部成功，未触发限流；但建议仍做缓存与频率控制（见 §5）。
3. 推荐**由 Go 后端统一拉取 + 本地缓存 + 降级链**，与现有架构一致（`backend/pkg/fetcher`、`cache`），同时绕开微信小程序"合法域名必须 HTTPS"的限制（新浪行情是 HTTP，小程序无法直连）。
4. 雅虎是日韩指数（KOSDAQ/TOPIX）、美债收益率的**唯一免费稳定源**，必须控制频率（建议 ≥30s 缓存）。

## 5. 调用注意事项

1. **微信小程序直连限制**：小程序 `wx.request` 的合法域名必须是 HTTPS 且需在小程序后台配置。新浪行情 `hq.sinajs.cn` **只有 HTTP**，因此全球经济/有色等页面**必须走后端代理**，不能小程序直连。
2. **编码**：新浪、腾讯返回 GBK，需转 UTF-8；东财/雅虎为 UTF-8 JSON。
3. **请求头**：新浪需要 `Referer: https://finance.sina.com.cn`（无则被拒）；同花顺建议带 `Referer: https://q.10jqka.com.cn/`；雅虎建议带浏览器 UA。
4. **时间/延迟口径**：腾讯美股、雅虎为延迟数据（非实时）；日韩指数多为收盘/延迟数据，页面需标注"延迟/收盘"而非"实时"。
5. **版权/合规**：免费源数据仅供自用展示，不建议对外转售；雅虎等数据受服务条款约束，注意高频抓取风险；行情页面应保留"数据仅供参考，不构成投资建议"声明（设置页已有入口）。
6. **业务归属说明**：以上均为公开接口，接口可能随时调整；建议把"代码→指标"映射收敛到配置/常量文件，便于失效时一键切换备用源。
